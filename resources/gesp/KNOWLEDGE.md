# GESP C++ 知识点准备图谱

下表的知识范围取自官方 PDF，拆点、先修关系、数学准备和掌握标准是教学候选设计，全部待审核。认证等级独立于小学年级。

数据见 [knowledge-map.json](knowledge-map.json)，逐条大纲原文见 [syllabus-clauses.json](syllabus-clauses.json)。

## 1 级

| 知识点 | 独立完成标准 | 应调查的易错表现 |
| --- | --- | --- |
| 计算机组成、操作系统与历史 | 区分CPU、内存、输入输出设备并说明一次信息流动 | 把存储设备、输入设备和输出设备混为一谈 |
| 编辑、编译、运行与调试环境 | 独立创建保存源文件并区分编译错误和运行结果 | 将编辑、编译、运行或解释视为同一步 |
| 输入输出与赋值 | 按指定次序读取输入并精确输出所需格式 | 把读取输入与输出提示文字混淆 |
| 标识符、关键字、常量和表达式 | 能判断名称是否合法并区分关键字、变量名和表达式 | 把cout当语言关键字或让名称以数字开头 |
| 变量定义、初始化与赋值 | 用状态表说明每次赋值后变量的值 | 把赋值当等式或使用未初始化变量 |
| 整型、浮点型、字符型和布尔型 | 为数据选择int、long long、double、char、bool并解释范围 | 把类型、取值和显示格式混淆 |
| 算术运算、优先级与自增自减 | 逐步跟踪带括号、优先级和自增的表达式 | 忽略优先级或混淆自增前后使用的值 |
| 整除与求余 | 能解释商与余数并独立处理数位或奇偶任务 | 把整数除法结果当作小数或漏掉余数条件 |
| 关系运算与相等比较 | 用边界值判断六种比较表达式真假 | 混淆=与==或漏掉等于边界 |
| 逻辑与、或、非 | 把复合条件翻译为逻辑表达式并举反例 | 把或者理解为必须同时满足 |
| 顺序结构与程序状态跟踪 | 按执行顺序用状态表说明每一步输入、计算和输出 | 用最后结果倒推并跳过中间状态 |
| if、switch 与条件选择 | 独立编写含互斥条件的分支并验证边界 | 多个if与if-else链的语义混淆 |
| for、while、do-while | 说明初值、条件、更新及终止原因并独立实现累加 | 漏一次、重复一次或循环条件不变 |
| break 与 continue | 用同一例子解释结束整个循环与跳过本次迭代的区别 | 把continue当作退出循环 |
| 注释、测试与基础调试 | 用正常和边界输入复现问题并解释修改原因 | 只试一个样例或仅改到输出碰巧一致 |

| 文件重定向与读写 | 区分标准输入输出重定向与文件流读写 | 文件打开失败后仍认为读入有效 |
