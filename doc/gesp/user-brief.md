# 用户研究材料与本次准备要求

来源：2026-10-20 当前会话用户粘贴。此文件为要点整理，非原文逐字镜像；官方复核结果单独记录，不覆盖用户原有观点。

用户要求原文：

> 把GESP纳入教学体系，全面收集题目，整理知识点，先做好准备，等另外一个任务完成后，再来做集成

后续指令原文：

> 那边任务完成了，你先补充，文档和内容都做好同步更新，然后提交

因此前置等待已解除，本轮补充资料并接入独立教研查询，更新内容、产品文档及恢复说明后作本地提交。

研究材料认为：GESP C++ 共8级，1～2级侧重语法，3～4级侧重程序设计和简单算法，5～6级进入算法竞赛常见内容，7～8级涉及数据结构、动态规划和图论。星级仅是用户材料的相对评价，不能作为CCF难度或通过率数据。

学习起点描述为四年级、尚未系统学习C++，建议先研究1～4级，重点观察3～4级的独立解题要求；先纸笔理解，再代码表达。材料建议少量新知识、多次独立应用，先巩固1～3级，再决定是否走竞赛路线。不预设六年级之前达到四级，不采纳固定倍速承诺。

材料给出的8个级别例题与3题思维小测已分别保存在 [非官方练习](../../resources/gesp/user-exercises.json)，其中两段C++参考代码也予保留。所有题目均保留“非官方”身份；补充约束和修订建议列在 `reviewFindings`，未混入官方题目计数。
