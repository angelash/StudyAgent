# GESP C++ 教学体系：当前接入与后续验收

状态：独立教研轨道和一级原创计编程试点已接入，完整学生课程与多级评测待建设。基准日：2026-10-21。

## 用户范围与当前结果

用户先要求全面收集题目、整理知识点，待另一项任务完成后集成；随后确认“那边任务完成了，你先补充，文档和内容都做好同步更新，然后提交”。前置等待已解除，本轮完成资料补充、教学衔接草案与教研查询接入。入口为 `/admin/gesp`，从既有知识与覆盖页面进入；资料见 [资料包](../../resources/gesp/README.md)。

“全面”指遍历CCF官网真题目录全部分页并保存全部链接的C++附件，另用3份固定提交版本的公开镜像补查缺链。108个实际开考组合中，105有正确对应的官网原卷、2用官方解析补充、1用公开镜像补充且官网来源仍缺。镜像不改写为官方来源，错链仍隔离。未公开评测数据与完整题解不凭空补齐。

## 与现有教学系统的关系

当前小学学科仍为语文、数学、英语，年级限定1～6。GESP以独立 `track=gesp-cpp`、`certificationLevel` 和命名空间接入 `gesp.ts` 契约，认证等级不当作小学年级，也不当作数学教材导入。

资料图谱仍为114个候选点；现有小学课程仍为258点、6,974题，GESP的3,132条机器索引不加入已发布任务数。`runtimeCompatible=false` 表示不能经现有小学课程包直接导入；`integrationStatus=research_workbench_only` 表示教研读取已实现。

## 已接入的流程

- 管理员、教师可读取知识、先修建议、官方条款和1～4级15单元教学草案；家长及学生身份不可读取研究题和答案。
- 题目按等级、场次、题型、来源、题面关键字和知识点候选分页查询。候选映射只代表关键字命中。
- 单题展示题面提取、未审核参考材料、来源身份、原卷页码和哈希；本地PDF读取核验字节。原始档案缺失或损坏明确返回状态，不生成替代题面。
- SQLite只读研究索引独立于业务存储，不加载全库到前端，不改学习范围、评测、作答、指导或历史报告。应用不编译、运行题目里的C++代码。
- 版本化资料、原始档案和索引分开；索引记录输入哈希，不匹配时要求重建及重启。

## 初始教学方向

四年级、尚未系统学习C++是学习起点，不是能力诊断。用户提及巩固不稳、容易漏条件，应通过真实作答核实，不预写学生标签。

[教学衔接草案](../../resources/gesp/TEACHING.md) 以15个单元覆盖1～4级49个候选点。区分纸笔理解、代码跟踪、独立编写和陌生任务迁移；以少量新知识、多次独立应用和延迟复测推进。5～8级保留完整知识框架，不预设考级时间或通过率。
