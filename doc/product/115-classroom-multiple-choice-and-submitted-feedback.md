# 课堂多选、明确反馈与原作答恢复

日期：2026-10-25，实施前规格。接续114的真实参考观察及105的M1/M2。此文件只定义后续开发，不能当作已经完成的功能；114工具交付后再实现。学校原生对接、收费与Marketplace继续排除。

## 1. 触发与最终行为

HyperKnow已观察的实际题目包含四选一、五项多选、两列选项和末项通栏；提交后选项锁定、正确项有绿色反馈，解析独立显示，Check转Next。当前本地诊断/训练支持17题型，但课堂ClassroomQuestion和PracticePanel仍只支持selectedIndex单选，不能用前者宣称后者完整。

本批让成人课堂的随堂练习与单元核查共用明确单选/多选协议：题目标明“选择一个”或“选择所有符合项”；多选可以反复勾选/取消，空集不能提交。提交锁定原集合，按私有冻结评分给出完整正确/错误反馈，刷新、切题、收起助教和重开课堂都保持原首答。旧版单选会话、资料课和旧题目不被原地变成多选。

复用现有提示、不会、跳过、复盘和原课程返回；不复制原站未知积分公式。正确率仍是本组首答统计，不直接写入正式掌握度或原因结论。

## 2. 共享数据与冻结兼容

ClassroomQuestion增加可选选择方式，缺省为single。多选题必须显式multiple，2至8个非空选项，至少两个正确项且不得全部正确；题目与答案/帮助分开冻结。ClassroomAnswerReceipt保留旧selectedIndex，增加明确选择集合和提交后反馈所需字段；旧单选回执按原索引读取，不批量改写历史。

新增统一的选择集合规范化/合法性校验：整数、边界、无重复、排序后集合相等，拒绝空集answered、含选项skip/dont_know、单选多个、单选字段与集合冲突。不得静默去重、截断或把非法输入当跳过。请求键hash使用规范集合及完整动作；旧格式重放继续按原hash协议识别，不能使既有幂等命令失效。

私有答案键兼容旧answer:number和明确的多选答案结构。只在已提交题目的公开回执里返回该题正确选项及说明；未答题、目录、提示、模型上下文、家庭可见草稿不得带未来答案。旧回执缺少反馈字段时仍可读原解析，不能根据最新题库猜出过去答案。

课程practiceVersion/内容指纹随新题目改变，新开会话使用新冻结版本；旧课堂保持原题与答案。资料课程生成/编辑协议本批继续明确单选，不让其schema凭空接受未支持多选；后续扩展单独审核。正式诊断/训练的17题型协议保持原职责。

## 3. 服务端首答与权限

ClassroomService.answer在原事务内核对账号/孩子/会话、冻结题、集合与原命令。第一次提交后题目和答案锁定；同请求重放返回同回执，同键异集合409。另一请求键重答不能覆盖首答、原时间、提示级别、作者接触答案事实或复盘计数。

评分采用完整集合相等；本批没有部分得分或猜测扣分，界面解释“本题须选全且不多选”。少选/多选都保留具体选择，并可在已提交反馈中比较正确集合；跳过与不会不伪装成作答错误。提示与助教仍记录实际辅助事实，不提前披露答案或改首答独立性。模型上下文只增加公开题型说明，不包含私有答案或新回执的正确集合。

公开投影、学习码授权、账号/儿童导出删除和真实备份冷恢复保留新增回执字段，内部命令和答案键继续隐藏。新题型不创建新的测量结论集合。

## 4. 前端完整流程

单选使用原生radio，多选使用checkbox及明确说明；选中状态不只靠颜色。独立练习两列，奇数末项通栏，390窄屏单列；助教展开时仍能看完整题干和选项，表格可以局部滚动。原有形状/序号保留，正确/错误/选中/漏选有文字与图标说明，不能把未选择的错误项显示为学生错误。

提交前Check、Skip、不会和逐级帮助，提交后锁定并显示Next/复盘。数字快捷键在题目区域切换选项，Enter提交；输入助教、弹层、图形放大或控件焦点内不能触发全局题目快捷键。屏幕阅读器能读题型、可选数量、已选集合、锁定状态和反馈。关闭读图后回到原按钮，题目草稿保留。

选择草稿按账号/冻结会话/题目区分，在切题与刷新后可恢复；缓存只包含本人选择和稳定提交命令，不包含答案键或令牌。掉回执时重发同命令，展示实际服务端终态；清空或重置仅作用于未提交稿。存储失败保留内存选择并提示，账号切换不读另一人的稿。

## 6. 接入复核与具体实施顺序（编码前）

在113候选c6e12e9上只读复核：classroom.ts的Question尚无选择方式，Receipt仅selectedIndex；classroom.service.answer在提交前严格校验单索引，以旧字段/可选disposition生成hash，再写原首答。classroom-curriculum.ts的私有keys仅number，随堂与单元核查分别生成冻结版本。PracticePanel在window注册数字/Enter快捷键，workbench的选择只在React内存，每次发送临时生成requestKey。以上是下一批接入点，尚无115业务实现。

实施按以下顺序推进：

1. 在共享契约增加缺省single的selectionMode、可选selectedIndices和提交后correctIndices/逐项说明。新增统一选择协议与校验助手；legacy保持原selectedIndex命令与完全相同的hash，新命令用明确版本和排序集合。出现重复/越界、模式冲突、空answered或带选项skip/dont_know时拒绝，不能自动去重。
2. 私有答案键支持原number与显式多项集合，公开题面不带答案。发布新代表题时更新内容/练习指纹；老课堂、原单选来源课和旧回执继续按冻结定义读取。资料课程生成/编辑仍只接受原单选schema，不能因共享类型扩展而静默放开新题型。
3. 服务端在原事务中处理首次提交和请求回放；集合完整相等才正确。逐项反馈只由该题冻结答案生成并随首答保存，不能回看时从最新题库重算。提示、作者曝光、skip/dont_know和独立计数沿用原事实口径；新题型不写入小学掌握度。
4. PracticePanel按模式渲染radio/checkbox、已选文字和选项反馈。数字/Enter事件只在题目区域生效，弹层或助教输入不触发。单选/多选的选择状态由同一集合控制，两列/奇数末项通栏及窄屏单列共用原练习布局。
5. 为workbench接入按账号/冻结会话/题目保存的选择草稿与完整待确认提交命令；刷新先读真实首答，同命令恢复掉回执。新输入不得覆盖未知终态，换号与迟到响应按epoch隔离，存储失败保留内存选择并提供副本。复用既有题目回看、原课堂恢复和只读旧版本入口。
6. 用至少三个代表微课及一个单元核查完成原创多选内容，逐选项解释和两级不泄题提示分别审核；自动化只证明协议与结构，教师审核继续单列。随后双库/最新删除账本/浏览器全回归、精确CI和主目录守护交付，不以单批几道题代表全242题或全部产品完成。
