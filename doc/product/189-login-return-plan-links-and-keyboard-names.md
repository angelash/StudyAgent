# 189 登录返回原位置、旧计划链接与侧栏键盘读屏名称

日期：2026-11-02。接[149深链兼容与验收清单](149-workspace-centered-interaction-restructuring-proposal.md)、[150总计划](150-integrated-delivery-plan-and-work-ledger.md)WS01/WS11/WS12、[31旧入口账本](experience/workspace-legacy-entry-ledger.md)E04/E21/E22及[188](188-legacy-parameters-and-family-pages-in-workspace.md)。证据见[收据](../evidence/2026-11-02/workspace-r1-login-return-and-keyboard-names/receipt.json)。

## 登录后回到原位置

工作台入口页会把当前地址作为返回地址交给登录页，但报告、学习档案、账号设置、学习任务、课堂、项目、白板、资料建课、原卷练习与复习、诊断、家长知识页、授权与资料页、管理页和顶部会话控件在未登录时给出的登录链接都不带返回地址，共22处。匿名打开某份报告或任务的深链，登录后只会回到工作台首页。

现在这些入口统一使用一个登录链接组件，在浏览器中取当前路径和参数作为`returnTo`；登录页沿用原有校验，只接受白名单中的站内路径，拒绝外站、嵌套登录和带凭据类参数的地址，学生仍不能返回家长与管理页面。白名单补入`/learn`、`/parent/dashboard`、`/student/knowledge`、`/student/mission`和`/chemistry`五个旧地址，保存的旧登录链接登录后先回到旧地址，再由原有服务端跳转到工作台位置。

## 只带计划的旧报告链接

报告类旧地址只带`planId`、没有原测评`session`时，原来会补上知识视图标签，计划定位丢失。按149“报告中查看计划后打开任务区的同一计划”，这种链接现在转到`/studio/tasks?view=plan`，保留学习对象、学科与`planId`；带`session`时仍打开原报告。服务端生成的首页动作与ICS订阅本就使用诊断页或任务区的计划地址，不受影响。

## 侧栏的读屏名称

侧栏原有六项的可访问名称一直是英文（Home、Courses、Calendar、History、Materials、AI Whiteboards），屏幕上显示的却是首页、课程、学习动态、历史、资料和AI白板，读屏用户听到的与看到的不一致；新增三项已经使用中文。现在九项的可访问名称都等于显示的中文，收起侧栏时仍由`aria-label`提供名称。9个测试文件里按英文名称定位侧栏的24处随之改为中文，键盘按键`Home`等不受影响。

## 验证

新增浏览器用例：登录返回3项，覆盖学习档案、学习任务、学习报告的匿名深链登录后回到同一地址并保留全部参数，旧登录链接返回`/student/mission`进入所请求孩子的任务、返回只带计划的`/parent/dashboard`后在任务区打开同一份真实计划，以及孩子从今日任务页用学习码登录后回到原页；键盘2项，覆盖桌面只用Tab到达九个入口和档案、设置，每项有可见焦点框且名称与显示一致、Enter打开页面，以及手机抽屉用键盘打开后Tab和Shift+Tab都留在抽屉内、Esc关闭并把焦点还给菜单按钮。

修改前复现分别为登录返回0/3（链接无返回地址、旧地址回到首页、学习码链接无返回地址）和键盘名称两轮：第一轮1/1失败来自测试点击页面空白处被拦截的测试代码错误，第二轮1/1失败正是六个入口缺少中文名称；原件全部保留。修改后专项18/0与133/0分批通过；构建xw87PdcIUKDaXJSQnDJZI上的整站第八轮646/647，唯一失败是首页“登录”链接带上了returnTo=%2F：首页不是可返回地址，参数毫无作用却改变了原有链接。这是本批引入的问题，现在仅对可返回页面附带返回参数，修复后专项19/0。另一次同步失败后误启动的构建login-keyboard-ui-build-second使用修复前源码，已作废且未用于任何验证。修复后的最终构建gUXB3iRftmNGkCVrd7IqK上，整站第九轮647/647零失败零重试零跳过，运行期间测试与夹具输入未变。

## 登录方式切换与现有学习身份

复现发现：从带原测评地址的家长登录页切换到学习码登录时，链接只到`/student/login`，原地址丢失；反向入口也使用固定地址，已有学生身份的“继续我的学习”同样只到首页。现在两种登录方式切换保留同一`returnTo`，实际认证后继续使用原有白名单、角色与敏感参数校验；已登录的学生也使用同一校验后的返回地址。原样式、文案、登录和学习码接口保持。

旧构建上的新增复现0/1保留。新构建`MHFmzlLIzoyAvHkLaUiwr`的5文件24项回归全部通过，覆盖两种登录切换、已登录继续原测评、旧链接、本人/他家、管理返回、键盘与移动布局；新测试类型检查通过。与旧构建647项整站的输入逐项比对，仅两登录页、共用登录链接和Next生成的类型路径不同，1609个构建输入及1911个API输入均有清单，不将两构建结果合称同一批。见[准确增量与结果](../evidence/2026-11-02/workspace-r1-login-return-and-keyboard-names/login-switch/receipt.json)。
