# GESP 独立学生编程轨道开发计划

2026-10-21，接续 GESP 原始资料与教研索引。目标不是把认证等级塞进小学年级，而是建立独立 `gesp-cpp` 学习范围、审题流程、编程运行证据和诊断闭环。小学三科已发布课程与 GESP 研究索引保持隔离。

## 范围与门禁

- 先完成 1～4 级 49 个候选原子点的定义复核、先修审核与可观察行为，再逐题审核题目结构、图示、代码、约束、答案和测试数据。5～8 级保留参考框架，不进入学生发布。
- 家长显式确认独立编程已学范围；认证等级、小学年级和教材学年不互相替代。学习范围与题目版本冻结到当前评测和历史报告。
- 每次评测区分概念理解、代码跟踪、独立编写、错误修复和陌生任务迁移。原始作答、提示暴露、编译错误、运行结果与测试结果分别保存，不只记通过/失败。
- 主观代码先保存源文件哈希与编译版本；隐藏测试只在隔离运行器中执行，不向学生或普通教研页面返回测试输入和期望输出。

## 运行安全

- Windows 开发环境通过 WSL 调用 Linux `g++`；Linux 部署直接调用本机工具链。启动时检查 `unshare`、编译器和资源限制能力，任一缺失即 fail closed。
- 编译和运行位于随机 `/tmp` 目录；使用独立 user/mount/pid/net/uts/ipc 命名空间，隐藏 `/mnt` 和用户主目录，不挂载仓库、数据库或媒体目录。
- 设置墙钟、CPU、内存、文件大小、进程数、打开文件数和标准输出上限；无网络、无宿主进程信号；超时后终止整个进程组并清理临时目录。
- 源码、编译命令、工具链版本、测试包哈希、资源限制、结果和退出码生成可复核收据。语言版本默认 C++17；题面明确要求时按审核版本覆盖。

## 产品流程

1. 家长确认学生已学的独立单元与原子点。
2. 系统按已审题族生成微测：概念/跟踪、受控编写、错误修复、新情境迁移。
3. 学生提交代码或纸笔解释；无编译器时仍可完成非运行题，但不得显示编程通过。
4. 隐藏测试、规则评分和教师量规分别记录；程序通过只证明当前测试集，题型和边界覆盖不足时保持未知。
5. 报告展示表面错误、失败测试类别、前置点证据和待验证原因；AI只引用真实收据生成指导。
6. 次日、3/7/14日使用同构新题和不同测试边界复测；记录独立性、迁移和保持。

## 里程碑

- G1：隔离运行器、资源限制、恶意源码与超时/泄漏负例。
- G2：独立学习范围、提交/复核数据模型与权限。
- G3：1～4级原子与题族逐项审核，首批完整单元试运行。
- G4：学生页面、报告、指导、复测和教师复核。
- G5：独立备份、新环境恢复、真实学生/教师与浏览器验收。

完成 G1～G4 代码与本地合成闭环仍不能替代 G5 的真实人员、跨设备和内容审核；未审核题目保持研究状态。
