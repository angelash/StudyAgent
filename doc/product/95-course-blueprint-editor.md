# 可编辑课程蓝图、学习预算与确认恢复

日期：2026-10-24。实现提交：`5740ef0a180d16b0bd0077ba2076ede1b3852b8e`。关联[完整建设计划](92-experience-and-content-master-plan.md)E02的XP-B02/B03/B04与后续XP-B05/B06；见[验收收据](../evidence/2026-10-24/course-blueprint-acceptance.json)。完整产品目标继续进行。

## 1. 从表单到课程

创建入口提供两个阶段：编辑目标和范围，然后审阅后确认。名称可留空按知识点命名；目标可编辑；知识点可按名称、领域或目标筛选、单独选择或清空。只列当前档案与学科已确认范围中已发布的点，每门最多30点。超过30点时要求主动分批选择，不把全部范围静默截断。

预览展示对象、年级/学科、目标、知识点数、单元、建议学习时段、每次预算、来源状态与缺口。每单元展开全部讲解、独立练习、迁移活动和单元核查的目标；缺少已审核教学卡时明确标示已有测量入口，不能误称可播放已审核讲解。

返回修改保留输入、选择和预算，使旧预览失效；必须重新预览才能确认。预览与取消均不创建课程。等待预览时可取消或Escape关闭并中止请求；确认写入期间锁定重复操作，等待取得回执。错误在对话框内说明，提供同一确认重试和重新核对范围。

范围在预览后改变时，创建重新校验当前知识点和内容指纹；非法或过期预览不能成为课程。重新读取范围保留名称、目标和预算，移除已经不在范围内的选择，再进行预览。

## 2. 时间预算与语言

新增可选`StudioCoursePace`，仅对带有`minutesPerSession`的新课程生成；既有无预算课程保留原结构。输入为5～60的整数分钟。

`course-pace-v1`按讲解篇幅与活动类型估算参考时长：讲解至少3分钟，独立练习5分钟，迁移和核查各10分钟。超过单次预算的活动拆为带part/parts的建议分段，连续活动按预算装入时段。每个所选活动均出现在节奏中，各时段不超过预算。

预算影响课程指纹，预览与最终保存必须一致；课程目录可展开建议时段并进入对应真实活动。分段是学习建议，不是新增作答证据、自动日历安排或已经完成的独立子任务。估计值没有伪装成实测耗时或教学效果保证。

当前语言沿用已审核材料，保留原语言与英文例句。任意语言翻译、外部资料自动生成完整课程尚未交付；不会用语言选择控件假装已经改写了课件。

## 3. 服务与确认回执

预览和创建共用严格命令Schema，显式空选择、越界预算、超过30点或范围外知识点均拒绝。创建复用预览的完整校验，避免只校验指纹而绕过范围资格。

修复原实现只取前五个知识分组的问题；合法选中的所有分组都生成单元。缺少讲解的警告仅针对所选点，不被其他未选点的草稿教学卡干扰。

既有课程继续保留当时结构和学习记录，需要补入新单元时重新预览；本批不自动重写旧课程。旧创建活动若缺少主体与命令摘要绑定，重放返回冲突并要求从课程列表恢复或重新预览，不把缺失字段补猜成可信回执。

创建请求按主体、档案、学科、命令摘要与请求键保存回执，绑定原课程ID。同键同命令直接恢复原课程；范围后来变化也不会改成另一门课。同键变更命令、不同主体或其他操作冲突。重放前仍检查当前访问权限。

同指纹的新确认复用已有课程，记录本次恢复回执，不重复发布创建事件。浏览器在确认失败后重试沿用相同键；返回修改后清除该键并要求新预览。状态与事件通过现有请求事务持久化。
