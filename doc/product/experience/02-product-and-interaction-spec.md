# 产品与完整交互规格

## 1. 统一入口、角色与上下文

增加统一学习入口 `/learn`。首次访问显示可用身份和真实操作入口；已登录时恢复当前档案、学科及可继续活动。家长可选择已授权孩子，学生只能看到自己的档案；管理员/教师的管理能力放在次级入口。没有孩子的成人仍可直接进入独立课程，不强制虚构儿童档案。

上下文以地址中的`student`和`subject`优先，其次为当前标签页的有效选择，再其次为服务端授权列表。不得把本地缓存身份当成授权；无效或撤权选择明确提示并重新选择，不能悄悄显示另一个孩子。标签页保留轻量选择，不把答案、令牌或报告正文复制进浏览器缓存。切换档案立即清空旧个人数据，过期响应不可覆盖新选择。

统一导航主要为：学习首页、课程、今日任务、资料与错题、学习记录；家长另有范围/报告/指导，教研另有内容/复核/运维。旧地址继续可用，跨页面链接携带档案、学科和活动ID。页面刷新、后退、前进和退出登录有确定行为。

## 2. 下一步与待办排序

首页只突出一个主要行动，其余作为可展开待办。初始排序为：未完成正式评测 → 已到期复测 → 待确认指导（家长）/等待监护确认（学生） → 未完成训练 → 今日计划训练 → 待核查原因 → 当前课程断点 → 缺少范围/初次评测。具体冲突通过领域返回的资格和可用性决定，不让只读卡片触发写操作。

每个行动显示“做什么、为什么、预计负担、保存情况、进入后发生什么”。范围未确认先引导确认；资料未审核不能成为正式测量下一步；暂停计划不能继续旧训练。复测未到期不提供绕过真实间隔按钮。

家长首页使用普通语言显示：已经知道的、还不能判断的、建议核查的、需要家长决定的。学生首页避免置信区间、规则码、样本权重等教研字段。证据详情可展开，但不默认形成信息墙。

## 3. 课程库与课程蓝图

列表提供关键词、进行中/未开始/完成、学科与课程类型筛选；记录当前条件。卡片显示标题、来源、单元/课时数、阅读状态和下一个可进入活动。独立成人课程、小学课程、编程课程标明适用对象与证据类型。

创建课程流程：描述目标/导入资料 → 选择语言、对象和可用时间 → 蓝图预览 → 显示内容与映射缺口 → 修改 → 确认。生成任务可取消、重试或保留草稿，不能先创建再假装预览。变更课程语言或资料版本要提示会话影响，不静默改写旧课堂。

大纲包含单元、讲座、微课、目标、先修、Learn/Practice、资料、项目和单元核查。点击目标可在触屏查看；课程和具体活动返回路径包含原单元与面板。阅读完成和独立测量状态并列呈现、分别标识。

## 4. 持续课堂

桌面采用白板主体、右侧对话、浮动工具条与底部当前字幕。移动端提供白板/对话切换，操作区不盖住字幕或提交按钮。窄屏保留当前句和播放状态。

播放状态明确区分准备、等待音频、播放、暂停、插问、检查点、完成与失败。板书对象具有出现顺序与讲解句绑定，内容为知识点、条件、步骤或结论；字幕只显示当前完整句，历史在对话侧查看。长句需按语义拆分，而不是用字符数自动伪造语音时间轴。

音轨结束后推进下一句；暂停冻结语音和文字计时；立即停止中断在途合成、播放和待生成回复；静音允许文字继续；插问后停在原讲解位置，回答结束由学生决定继续。重试不重复追加笔记。退出显示保存状态，重新进入从当前句开头恢复。

设置支持音色、语速、字体、背景与引导。缩放、翻页、笔记导出、分享范围、键盘和拖动宽度均有可操作语义。分享不能携带孩子隐私或私有答案。

## 5. 图像、表格、公式与代码

图像分原页/已有资产/生成插画/可执行图示，按用途标来源。比较表按行或列随讲解出现，表头固定，手机可横向查看，不能截掉关键单元。公式使用可复制的KaTeX/结构化表达；图像公式保留原页和候选文本。

动态图优先受控数据协议，如分数条、数轴、韦恩、流程、比较、坐标、几何。生成HTML不直接注入主页面。生成图片先显示可读文字和占位状态，完成后插入当前讲解位置；失败可重试，当前课堂仍能继续。

代码实验包含题意、语言、初始代码、输入、运行/停止、结果与错误。JavaScript与C++分别采用现有沙箱和隔离运行器。输出限长、不联网、超时可恢复；测试输入与私有答案分层，模型反馈不能泄漏隐藏测试。

## 6. 练习、项目与单元核查

Learn与Practice共享课程上下文但独立保存。练习页显示题序、题干、图示、专用输入、提交/跳过和保存状态；支持键盘与触屏。提交前不泄漏答案，提交后给出具体依据、误区和建议；提示后答对明确标辅助。

不同年龄使用适合的语句长度和触控尺寸。速度奖励只作为可选体验，不进入掌握估计；不鼓励为速度牺牲解释。重复练习明确标识，不能重复累积独立测量样本。

项目分阶段保存产物、版本、证据和量规；AI建议与教师结论分开。单元核查使用新的独立题族，复用课堂题时标复习，不能显示成独立测验。反馈后提供继续学习、复习误区或请求核对的单一主要动作。

## 7. 资料与纸面工作流

导入入口明确区分拍一题、拍整页、多页PDF、已有题卷和教材。采集先预览方向、裁剪和页序；保存原件；处理可以取消、重试、断点恢复。去笔迹不得覆盖原件；模糊、表格/公式不确定处可点回原图。

资源按教材→章→课时→页→题/答案定位，保留版本和原页。检索筛选用服务端分页；用户看得到完整度与可用动作，只有目录的记录不能展示不存在的正文。

错题包含原始表现、错误步骤、个人标签、订正、独立复做和复习时间。打印/导出先预览题序、留白、答案分离、页码与来源；任务完成才提供文件下载。打印失败或中断不丢选题清单。

## 8. 日历、历史与失败恢复

日历保留月/周、当前日期、确认状态和计划来源。手动安排可编辑/完成/重开；计划由计划服务修改；订阅只读。来源管理按身份隐藏不可用操作，后端仍独立校验。ICS继续手动导入、同步和导出。

历史可按档案、学科、类型和时间检索；打开恢复具体会话而不是泛跳首页。失败状态说明当前已保存什么、可重试什么、是否会重复计数。断网时不能假装提交成功；重新连接后先读取服务器状态再恢复。

所有页面补齐加载、空数据、无权限、撤权、版本冲突、取消、超时和部分成功；弹窗有焦点约束与归还，减少动画与屏幕阅读顺序可用。
