# 教材课时审核工作台

2026-10-21，接续完整语文教材源和映射候选交付。本批把候选材料变成可连续操作的审核工作台，同时补齐内审原页阅读。

## 候选证据筛选

课时清单新增“全部依据 / 有PDF候选 / 无可靠候选”筛选，并分别显示数量。原“候选”状态标签改为“已存候选”，避免与尚未保存的 PDF 候选混淆。筛选由服务端执行，结果仍按学科、年级、学期、映射状态和页码分页；“有PDF候选”也可继续与“待映射”组合，用于优先处理已有证据的课时。

接口返回的候选数量覆盖当前映射状态下的全部课时，分页不改变统计。候选只会预填人工关联选择，不会创建映射版本，不会进入已审核状态。服务端继续按当前教材的学科、年级、学期和已发布原子点过滤候选。

来源可用性进一步按“全部来源 / 有同版原卷 / 无同版原卷”筛选。每条课时同时显示来源徽标；无原卷时仍可查看目录和已有映射，但服务端会区分版本年份冲突、来源缺版本、候选不唯一和完全无候选。这样教研人员可以先处理具备原页证据的课时，也能单独查看需要补教材来源的记录，而不会把空原卷误当作没有课时。

页面顶部汇总全部教材记录的来源状态，运营可以直接看到同版原卷与待补总量，以及冲突、无候选、歧义和缺版本四类原因；当前448条记录中250条有同版原卷、198条待补。

## 内审原页

打开有完整源文件的课时后，教研工作台同时显示教材印刷页码和 PDF 物理页，并以候选审计保存的逐课时页范围定位内嵌阅读或新窗口原卷，避免 0～9 页的册内偏移把审核跳到相邻页。原页接口只允许管理员和教师访问，响应不包含本地绝对路径，使用私有禁缓存策略、PDF 类型限制、内容安全策略、ETag 和 HTTP Range，浏览器无需一次载入整本 10～17 MB 教材。

源文件首次访问时以流式计算 SHA-256，并与教材清单一致后才提供字节；结果按路径、文件大小和修改时间缓存。路径必须位于受控资产根目录，解析真实路径后再次防止目录越界和链接越界。文件缺失时提示恢复独立备份，同长度篡改会以字节校验失败拒绝，不会把损坏原卷继续展示。

注册目录没有课时树时，只要同版原卷已安全绑定，工作台仍显示整册内审阅读器，标题明确写出首页和总页数。它只打开原卷第1页供版本与内容核对，不据此生成课时或知识映射。

如果元数据完成绑定而Git忽略的PDF未部署，页面明确显示缺资产状态和恢复指引，不把空阅读器当成功。

## 验证和边界

全仓生产构建和类型检查通过；文档链接检查覆盖 94 个 Markdown 文件和 188 个相对链接，缺失 0，收据见 [文档链接证据](../evidence/2026-10-21/doc-links.json)。默认回归为 155 个测试文件、698 项，692 通过、0 失败、6 项 PostgreSQL 默认跳过。新增两项源文件单元测试验证元数据不泄漏路径、哈希一致才可服务以及同长度篡改被拒绝；跨教材真实目录测试验证 523 个教学课时的物理页范围均落在对应 PDF 内；跨教材 API 测试验证有候选与无候选筛选总数守恒、候选仍无人工映射版本、家长访问原卷被拒绝以及真实 PDF Range 206 响应。收据见 [回归证据](../evidence/2026-10-21/textbook-review-workbench-regression.json)。

当前自动化验证覆盖接口、权限、字节校验和分页契约。Browser Runtime 仍受既有硬阻断，未把构建或 HTTP 测试冒充实浏览器页面验收；内嵌 PDF 阅读器在不同浏览器和触控设备上的视觉操作仍需真实浏览器复验。523 个课时仍需教研人员逐项确认，候选筛选和原页阅读提升审核效率，不替代人工结论。
