# 课前声音试听与真实音色说明

2026-10-25，下一批编码前规格，接续105的M1与114课堂工具。116指导建议继续按独立验收发布；本文件只承诺下一批实现范围，不声明已有声音等价。

## 1. 参考观察与实际缺口

已登录HyperKnow的社会学白板在本日重新观察：设置内有Warm、Calm、Bright、Gentle、Professional、Lively六张音色卡，每卡独立Play sample；有0.5至2倍语速、手写/标准字体、背景点网格和重新导览。参考截图及控件边界留在本地data/research/hyperknow/2026-10-25-settings-recheck，未取得原CSS/字体/DPR或音频字节。打开动画会改变边界，不能将本次坐标当作完整原CSS。

当前SpeechService给MiniMax和OpenAI各列五个供应商ID；设置里的描述按数组位置循环分配，因此“平静”“明亮”等描述并没有来自对应供应商元数据。useVoicePreview只读已出现的当前句，首个讲解尚未出现时无法试听。114已完成独立试听的停止、切换、关闭和播放速率恢复，但没有课前固定样本，不能把它记录为参考站六声线已经还原。

本批要使用户进入课堂后即可比较真实可用音色，再选择并开始讲解。试听不能提前读取课程句子、修改课程进度、自动换音色或与讲解重叠。声音是否接近参考站仍需逐声线真实听感对照。

## 2. 服务端样本与能力契约

增加明确的课堂音色元数据：真实voiceId、供应商显示名、语言、可核实的说明、样本是否可用及默认项。显示名和说明以人工核对的实际ID配置，移除按数组位置生成描述；无法核实特点时只显示供应商名称/语言，不把一个声音重复包装成多个独立声线。

实施时读取集成aigw-mediakit-tts技能并核对已有live-avatar与StudyAgent音色资产/适配器，优先复用已验证音频与来源清单。用可用供应商目录核实候选ID，冻结本批样本版本及其音频摘要。只把真实已调通的音色列为可试听；六种角色是参考目标，未取得或无法匹配的角色明确保留缺口，不靠复制同一个voiceId凑齐六张卡。

增加POST learning/classroom/sessions/:id/voice-preview，输入仅voiceId与样本版本，不接受任意文本。服务端重新鉴权当前课堂并校验当前供应商允许的voiceId，使用版本化的中性原创样本文字，例如“我们先把问题看清楚，一步一步来，再用新的例子验证。”，不引用学生信息、未展示讲稿或题目。样本接口不会写cursor/revealed/sentenceCursor、答案、课堂消息或能力证据。

复用SpeechService信号取消和现有MiniMax/OpenAI解码，严格验证可播放格式。样本按供应商、实际模型、voiceId、文本版本与音频格式标识；缓存只能包含固定公共样本，不将家庭讲稿音频混入。成功记录真实供应商和内容摘要，错误保留可重试状态。当前目录与样本版本变化后不误用旧模型/音色的缓存。无供应商时仍可使用文字课堂，控件说明真实原因。

## 3. 前端体验与生命周期

设置在讲解开始前即可试听中性样本；已展示当前句保留为独立可选的“试听当前句”，明确两者来源。点击试听先暂停当前讲解，播放本音色样本且不改变当前选中音色；同项再次点击停止，换项停止前一项。关闭设置、换课堂、换号、页面卸载、网络取消和播放失败时释放精确AbortController、Audio和对象URL。迟到响应不能复播或覆盖新选择。

语速滑杆实时作用于当前试听，试听结束后保持原选择和学习位置。失败说明出现在对应卡或设置内，不阻塞关闭。鼠标、键盘与触屏均能区分选择和试听；radio箭头导航不触发播放，试听按钮有明确名称与按下状态。手机一列或两列布局以真实可读性验证，避免描述裁切和底部控件遮挡。

优先沿用当前已观察的460px设置布局、圆角、卡间距及播放控件，逐状态留应用截图。原站字体、精确CSS和真实声音仍未取得时，只报告本次对照修正，不宣称100%复刻。

## 4. 验证与发布

服务测试验证未开始课堂可试听、任意文本/未知voiceId拒绝、本人/学生角色边界、跨账号拒绝、取消信号传递、供应商失败及样本版本隔离；前后读取完整课堂快照，证明进度、答案和证据未变。固定样本不含家庭信息，隐私导出不混入其他人的音频。

浏览器用独立合成账户验证课前试听、选中与播放分离、换音色、停止、关闭、语速、网络掉线和迟到响应、刷新/换号、键盘焦点与390/768/1440布局。真实供应商小调用检查每个拟上线voiceId的容器、解码、时长与播放，保留失败而不把目录存在当成已调通。真实听感与手机扬声器/耳机仍单列实机门槛。

通过适当本地验证、完整API/浏览器、精确CI后，再做主目录停服一致备份、真实生产构建、原配置校验和跨一分钟守护观察。保留115/116原运行收据和回退构建。M1全部参考状态、完整课程/自由白板、M2～M7、教师/实机/长期学习效果继续保持原范围。
