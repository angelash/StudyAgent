# 完整开发计划与验收矩阵

2026-10-19 基线。目标不缩减为少量演示题或文档。每个里程碑都包含代码、数据、测试和必要运行证据；可分阶段交付，但最终目标只有在全部验收后完成。

## 1. 工程边界与架构

保留 Next.js / NestJS / contracts monorepo。建立明确的身份、课程图谱、测量、诊断、指导、内容资产与运营边界。确定性评分和测量不依赖 LLM；AI 是受约束的解释与建议层。大规模原始题卷由索引库和文件存储访问，不能装进全量 JS 数组或整库返回浏览器。

生产部署使用事务数据库与持久任务/outbox；本地交付提供无需额外外部服务的持久模式，保持相同数据隔离、幂等与证据语义。已有数组实现只能作为兼容迁移入口，不能把重启丢数据的运行方式标为完成。存储实现选择与限制必须有实际重启/并发验证，PostgreSQL 路径也必须独立验收。

大资产位于独立 `data/assets`，与代码分开备份；清单、校验工具、数据结构与小型教学种子可版本化。源数据库一致性快照、媒体、模型和原始资料均搬入，不能只写指向另一工程的绝对路径。原始研究资料不包含账户令牌/会话/私密配置。内容发布资格与原始归档资格分开。

## 2. 里程碑、实施任务及完成证据

### M00 需求归档（开发前提交）

交付现状评审和证据、完整需求、测量设计、本计划与实施记录。验收：文件完整、链接有效、Git staged 仅本任务文档，`git diff --cached --check` 通过并有本地提交哈希。

### M01 安全与持久底座

- 明确注册/登录、受控管理员引导、过期与撤销、限流、主体隔离与授权绑定。
- 关闭草稿/答案泄露、AI 匿名历史与越权；参数校验、媒体与 HTML 安全、CORS 和审计。
- 业务存储事务、迁移、唯一约束、幂等响应、可恢复任务/outbox、健康/就绪。
- 修正重复提交完成任务、空数字转零等已复现缺陷。

证据：六组已知漏洞回归、越权矩阵、恶意输入、并发提交、失败事务回滚、API 重启后续答/计划/会话恢复、备份恢复。覆盖 AUTH-*、OPS-01/02、ASSESS-03/05/06、TRAIN-01。

### M02 完整资产迁入与来源索引

- 盘点源目录和依赖、创建一致性数据库备份、按媒体清单断点复制、逐文件哈希、记录错误与可重试状态。
- 搬入学习软件调查原始/整理材料、题卷快照、完整可用媒体、模型与可复用处理工具；保留来源和历史验证条件。
- 建立资产清单、规范化纸卷/题目/资源/媒体索引、原始结构与缺口记录；可重跑、幂等、全量对账。
- 将 11 款学习软件的能力映射为产品功能与来源证据，不复制账户数据。

证据：源/目标行数、独立快照校验、媒体字节/哈希与缺口列表、工具模型启动测试、重复导入不增数据。覆盖 ASSET-*、CONTENT-03/04/05。

### M03 内容生产与完整试卷体验

- 文件上传、持久异步导入、PDF 文本与扫描分支、版面与题目关联、规范化协议和候选质量标签。
- 来源/许可/媒体/评分/知识映射的独立审核门禁；批量复核发布与回滚。
- 服务端分页与多维试卷检索、整卷/单题、PDF 预览、打印、收藏、来源与完整度提示。
- 17 类协议逐一提供输入、校验、渲染、评分/复核路径；不支持能力明确禁用，不能静默使用通用文本框代替。

证据：结构卷/部分卷/PDF卷各自的真实样本、上传中断与恢复、富媒体一致性、XSS负例、题型矩阵、手机与平板浏览器流程。覆盖 CONTENT-*、ASSET-04/05、ASSESS-04/05、TRAIN-02。

### M04 课程进度与原子知识图

- 一至六年级三科课程与教材映射；年级/学期/教材/已学课时选择和版本快照。
- 原子点定义、可观察行为、维度、量规、先修图；导入编辑和无环校验。
- 题目主测/先修/次测映射、候选与审核区分；量化题按题族、维度和课程覆盖建立索引。
- 覆盖缺口看板，人工与 AI 辅助标注；审核后的映射才能提高测量可信度。

证据：不同教材同年级/不同学科进度隔离；未学内容不混入；循环关系拒绝；历史版本保留；每学段学科覆盖审计。覆盖 SCOPE-*、KG-*。

### M05 分层评测与多维量化

- 初始/单元/阶段/微测/验证/复测蓝图，范围快照、去重与覆盖解释、时长与停止条件。
- 分组答题、断点恢复、独立与提示证据、不可变响应与重评。
- 确定性多协议判分，主观量规评分和复核队列；知识点估计与区间、样本、维度和未知显示。
- 评测报告能展开证据；不能将正确率直接叫实际能力。

证据：测量设计第9节边界用例、蓝图重放、评分金样本、模拟学习轨迹、范围缺题行为、真实浏览器首测→报告。覆盖 ASSESS-*、MEASURE-*。

### M06 深层原因分析与验证

- 表面错误编码与可观察事实；先修、理解、步骤、表示/迁移、保持假设及替代解释。
- 支持/反证引用、状态机、下一验证动作、题族与对照探针。
- 验证后更新假设；冲突保留未定；人工复核、反馈和重评链。

证据：独立算式通过而情境失败、先修失败、延迟失败、误触/歧义与反证等路径；每个结论可追溯；AI 不得生成无来源确定性根因。覆盖 DIAG-*。

### M07 AI 指导与训练闭环

- 规则形成计划骨架，AI 以真实上下文生成结构化说明；模型/提示版本、引用与预算验证、超时降级。
- 计划确认/调整/暂停；活动、资源、目标、成功标准、复测和家长指导。
- 今日任务、渐进提示、错题本、分步恢复与正反馈；完成基于唯一活动。
- AI 对话按主体隔离、按需检索、可取消；不每次启动联网子进程。

证据：无API key/超时/非法输出仍可完成；三科学生/家长对话；引用越界被拒；日预算与先修优先；独立/提示区分。覆盖 AI-*、PLAN-*、TRAIN-*。

### M08 间隔复测与可验证复盘

- 次日/3/7/14日队列、到期提醒、同构新题、迁移与保持测试。
- 干预事件绑定前测/活动/后测；同量规比较、样本与区间；假设关闭与重开。
- 家长日/周报、知识地图趋势、可比性、未验证解释和下一步。

证据：时间推进的复测测试、同题重复不能证明迁移、保持失败重开、样本不足不宣称提升、历史计划版本可查。覆盖 REVIEW-*、MEASURE-*、DIAG-*。

### M09 产品界面与运营

- 一致的中文学生/家长/教研/运营导航，首次引导、恢复、错误与无数据状态。
- 360px手机、平板、桌面；键盘与触控；加载性能、焦点、标签、减少动画。
- 运营看板显示导入/题源/媒体/知识映射/测量覆盖/复核积压/任务和 AI 质量。
- 资产管理和数据导出/删除可审计；不在学生流程显示实现参数。

证据：不同视口截图、键盘流程、端到端用户旅程和运营审核回路。覆盖 UX-*、AUTH-05、CONTENT-*、QA-01。

### M10 部署、恢复、性能与全量验收

- 全新环境启动、配置样例、数据库迁移、离线资产路径、PostgreSQL生产部署、任务进程、服务健康。
- 备份/恢复/升级演练、任务恢复、日志指标、容量与性能基准。
- 完成需求逐项验收表和证据索引；完整测试构建通过；本地分阶段提交；不自动推送或远程发布。

证据：`npm run build/test/lint`、端到端报告、数据库重启/恢复报告、完整资产核对、性能样本、已知限制与未完成清单为空。覆盖 OPS-*、QA-01 及全部需求最终审计。

## 3. 开发顺序与并行工作的边界

M00 必须先提交。之后 M01 先行；M02 复制和校验长任务可与不依赖资产的课程/测量开发交错推进；M03 与 M04 共同支撑 M05；M06→M07→M08 形成诊断闭环；M09 随功能同步实施，M10 做全量交叉验收。不因已有样例通过就跳过资产或课程覆盖。

本基线不虚构人日承诺。完成度以验收证据计算，不能以文件数、代码行数、题库原始条数、规划打勾衡量。

## 4. 验收追踪规则

实施记录须为每项写明：需求 IDs、实现文件/接口/页面、提交哈希、测试用例和命令、运行时间与数据版本、证据路径、状态（未开始/进行中/待验证/通过）及缺口。自动测试只证明其覆盖的行为；外部工程历史证据不直接证明 StudyAgent 已支持。

基础门禁：不泄漏答案/他人数据、不丢首次响应、不重复计分、不跨进度兜底、不伪造掌握和根因、不将不完整原卷补成“完整恢复”。以上任一失败阻止产品完成。

最终审核由需求逐项反查当前实现和证据。存在未完成/未验证项时持续目标保持进行中，不能把范围缩成已完成部分。
