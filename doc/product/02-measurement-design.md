# 知识诊断与量化测量设计

版本：1.0，2026-10-19。适用：`SCOPE-* / KG-* / ASSESS-* / MEASURE-* / DIAG-* / PLAN-* / REVIEW-*`。

## 1. 核心实体与不可变证据

`LearningScope` 保存学生、学科、年级、学期、教材册次、已学课时/点、当前课时、确认来源、版本和生效日期。`KnowledgeAtom` 保存操作性定义、年级/学期、课程映射、主维度、达标标准；`KnowledgeEdge` 保存先修/易混/迁移关系与审核版本。

`MeasurementItem` 指向题目版本，包含主测点、前置点、主维度、难度、预期时间、评分量规、题族、验证角色、可观察错误编码和审核状态。原试卷的学段、章节只是候选元数据，不能直接替代经过审核的点级映射。

`AssessmentBlueprint` 保存范围快照、分层目标、每点题量、难度比例、覆盖阈值、时长与停止规则。`AssessmentSession` 固化蓝图、选择理由、题目/量规/知识图版本与种子。`ResponseEvidence` 保存唯一提交键、首次响应、尝试序列、有效时间、提示、主观评分状态、错误观察及评分版本。

`MasteryEstimate` 保存学生/点/维度、有效样本、估计值、区间、状态、算法版本、证据 IDs 与更新时间。`DiagnosticHypothesis` 保存症状、候选原因、支持与反对证据、待验证任务、验证结果与状态机。

`GuidancePlan` 保存证据、目标、行动、预算、验收、复测与家长确认；`InterventionEpisode` 绑定计划、前测、活动和后测，`Retrospective` 产生可比性、差异与下一步。所有新推断生成新版本，不能覆盖原始响应。

## 2. 知识点拆解规范

每个原子点须满足：一个明确行为可被两个以上不同题族观测；能给出独立成功标准；能安排针对性教学活动；先修关系可解释。主题/章节可以作为聚合节点，但不能直接赋予精确掌握值。

数学示例：三位数减法 → 相同数位对齐 → 判断本位是否需退位 → 从相邻位借 1 并换算为 10 → 修改被借位数 → 跨零连续退位 → 逐位相减 → 用加法验算。应用题还拆分信息提取、数量关系表示、运算选择和单位/答句。独立算式错误与读题错误需要不同探针。

语文示例：段落理解拆为显式信息定位、指代追踪、句间关系、基于证据推断、概括与表达；英语将词形识别、词义、语序、语法和听辨分开。一个开放表达题不能同时确定所有维度。

先修边必须无环、不得自指，且在课程版本中有效。编辑图时检测环并显示路径；删除已被评测引用的点改为停用。历史报告按当时版本解释。

## 3. 范围与组卷算法

1. 校验学生授权与学习范围，获取已学点以及允许追溯的先修闭包。没有进度记录时引导确认，不能默认为整学期全部已学。
2. 过滤：发布、来源可用、媒体齐全、协议可评分、范围匹配、测量映射已审。未知映射只能用于练习，不能冒充标定题。
3. 初测按领域覆盖、基础/理解/执行/迁移组合形成蓝图，提供约 10–20 分钟的分组活动；微测 3–8 题，点级验证通常 2–4 题。实际数量由点数、时长与可用题决定，不强行凑数。
4. 优先近期未见题族，混入稳定锚题；每点至少两个题族时才可形成初步估计。记录候选数量、选中数量、缺口和未测点。
5. 分支规则以观测为依据：基础执行失败 → 前置探针；基础成功、情境失败 → 表示/迁移对照；立即成功、延迟失败 → 保持验证。
6. 停止条件：题量/时长达到、区间足够窄或剩余题无新增证据。终止也保留局部报告，显示未测范围。

严禁以所有科目前几题代替组卷、跨年级兜底、把 1 题推广到全章节、用 AI 临时生成的未审题填补测量覆盖。

## 4. 评分与证据权重

确定性协议负责单选、无序多选、判断、数字容差、约分等值、单位明确的数字、多空逐项、匹配与排序。公式规则使用受限解析，不执行用户表达式。步骤题按量规分别评分。开放题的 AI 评分为建议，低置信度/无量规/缺上下文时置待复核，不把缺失评分计作答错。

每份证据权重 `w = mappingWeight × independence × novelty × recency × scoreReliability`：

- 主测点映射清晰为 1；次测点按可观察步骤分配，总权重不凭空扩张。
- 首次独立作答为 1；轻提示 0.6；显式步骤提示 0.3；看过标准答案后 0，仅保留练习记录。
- 同一题首次测量为 1；同题重复不会新增测量样本；同题族近期重复最多 0.5。
- `recency = 2^(-ageDays / halfLifeDays)`，初始半衰期 60 天，规则可版本化；衰减导致不确定性增大，不自动宣称遗忘。
- 未复核主观评分不进入高置信估计；无效、跳过、媒体损坏不计错误。

权重及阈值是可解释的产品规则，记录 `rule-estimate-v1`，尚不是经过学生样本标定的 IRT 参数。

## 5. 初始掌握度模型

对点与维度使用保守 Beta 估计，先验 `a0=b0=1`；对经审映射、独立证据累积 `a=1+Σw×score`，`b=1+Σw×(1-score)`；点估计 `a/(a+b)`。区间用 Beta 分位数计算，若采用可用的保守区间近似必须在实现与报告中明确，不能称为精确后验区间。

同时展示原始正确/有效数与有效样本权重，避免把先验导致的 50% 显示成真实得分。`n=0` 状态为未知，不能显示掌握；`n<3` 或独立题族不足为证据不足；有效样本 ≥ 3 才可初判；稳定掌握需要有效样本 ≥ 6、至少两个题族、独立通过、迁移和延迟证据，并且区间下界达到设定标准。低分但证据不足仅显示“需进一步核查”。

维度保留理解、执行、表示/迁移、保持、独立性；没有相应题就显示未测。领域聚合以覆盖比与最低可靠度共同显示，不对未测点填零、不对少量点外推。作答时间单独列事实，只有足够同等条件样本才形成“流畅性”估计。

后续标定路线：匿名收集题目正确率、区分度、作答时间分布、评分者一致性及差异项指标；教研复核；留出学生验证集与对照；通过后升版本并保留旧结果。未完成标定不声称常模等级。

## 6. 表面表现与深层假设

状态机：`proposed → testing → supported / contradicted / inconclusive → monitoring → resolved / reopened`。

例：学生在跨零退位应用题答错。

1. 已观察：该题算式或步骤 X 错；记录题目、响应与评分理由。
2. 假设 A：跨零退位操作不稳。验证：无文字负担的退位算式与口头/步骤分解。若通过多个题族则反对 A。
3. 假设 B：数量关系表示受阻。验证：同样数值的直接算式、图示问题和文字题对照。只有对照模式持续出现才支持。
4. 假设 C：前置位值概念不足。验证：十进制换算、位值、退一作十独立题。失败支持；通过反对。
5. 环境、疲劳、误触、题意歧义等替代解释保持可记录，不能自动判断。

每个假设最少有直接证据引用和可执行验证动作。支持标准默认两个独立题族呈一致模式；反证优先暴露；互相冲突则“未定”。深层原因只到教学上可观察的障碍，禁止从答题日志推断疾病、天赋或家庭归因。

## 7. 指导计划与 AI 边界

确定性层：计算优先级（当前课时阻断程度、缺口、可靠度、复测到期、用户预算），选择经过审核的干预活动和验证题，形成可执行骨架。AI 层：在骨架、证据和学习背景内组织解释、引导提问、示例和适合孩子的表达。

结构化行动包含 `knowledgePointId / hypothesisId? / evidenceIds / targetBehavior / activity / resourceIds / minutes / successCriterion / retestAt`。引用不存在、超预算、指向未学内容、替换原始数据或提出无依据原因的结果拒绝并退回规则计划。AI 不可用时骨架仍可执行并标明来源。

一次计划优先 1–3 个重点；每日讲解、练习和复测时间总和 ≤ 用户预算。支持计划版本、确认、暂停和调整。渐进提示从目标提醒、关键关系到步骤支架；已给答案的作答不增加独立掌握证据。

## 8. 验证、复测与复盘

干预前保留基线和假设；训练中采集步骤与提示；结束后同构新题检验独立执行，再用变式检验迁移；1/3/7/14 日安排保持测量，成功延长、失败回到可验证的先修点。

复盘先判断可比性：同一知识/量规版本、相近难度、题族是否独立、是否提示、间隔是否足够、样本是否足够。显示前后估计与区间、有效样本、观察到的改进；区间重叠或样本不足不能断言干预有效。不能因完成任务就自动关闭假设。

## 9. 必须通过的边界用例

无证据为未知；一题不能稳定掌握；重复提交不增加独立证据；提示成功不等于独立成功；未学点不进常规评测；有环图被拒；综合错题不能确定多个根因；反证改变假设状态；缺题明确减覆盖；无 AI 仍可执行计划；跨家长请求被拒；中断恢复保持相同题序；重评有新版本且保留原作答；训练成功但延迟失败重开问题；主观未评分不计为错误。
