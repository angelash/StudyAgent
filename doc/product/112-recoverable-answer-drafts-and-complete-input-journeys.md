# 可恢复作答草稿、首次提交与17题型连续旅程

日期：2026-10-25，实施前规格。接续[计划105](105-development-plan-status-and-next-milestones.md)、[题型协议17](17-structured-answer-delivery.md)与[项目附件111](111-project-attachments-and-frozen-file-evidence.md)，对应XP-E01/E02、I01/I02、K02/K05。先提交本规格，再实现；111最终运行收据提交前不提交本批业务代码。学校、计费和Marketplace继续排除。

## 1. 核对后的现状与目标

共享题面已经有17类响应、MathLive、结构输入、绘图、图片和录音，诊断与每日训练都有草稿接口；媒体输入已经按活动/会话/题目key挂载，本批继续复用。现有协议/评分与媒体测试不能替代17类完整浏览器旅程。

实际断点：诊断与训练草稿只接受answer，没有写修订或稳定回执，两个标签页和慢请求可覆盖较新稿；前端防抖保存的晚到成功/失败提示没有题目范围检查。首次提交和训练重试的命令未完整保存在浏览器，丢回执时可能重新计算时间或仍显示旧题。绘图与资源失败状态也须按冻结题目范围核对。以可复现用例核实并修复，不把代码风险直接宣称为已经观察到的学生事故。

目标是学生每一处输入都有清楚的本地/服务端保存状态；刷新、弱网、暂停、换题、换活动、换身份、旧标签和提交丢回执都能保留真实作品。草稿、提示、首答、订正和能力证据分别记录，恢复操作不能补造已作答或掌握事实。

## 2. 两条正式路径共用草稿v2

诊断继续使用diagnosticDrafts，训练继续使用practiceSessions内的drafts，不将二者或项目附件合成同一证据。保存对象可增加可选修订、协议和命令摘要；旧记录按修订0读取，不批量重写答案。完整题面/答案/量规仍使用原冻结快照。

现有渲染读取继续返回原draft形状，另给公开的草稿状态：修订、保存时间、协议、是否可编辑/已有首答。读取不创建草稿或学习事实；公开响应不包含内部命令日志或评分键。v2写入携带expectedRevision、requestKey和完整未截断答案，验证当前活动、题目、协议及媒体归属后提交。相同命令先识别已保存回执，同键异参和过期修订冲突；记录确认修订与当前修订，不能把较旧命令的确认当作当前内容已经保存。

旧客户端的写入也推进服务端修订，防止新客户端误把旧写入当修订0。一份草稿进入v2后，缺少修订/命令键的旧写入明确要求刷新，不能绕过并发保护。旧无草稿/旧未升级草稿保持原有兼容路径；旧命令、首答和历史答案不重写。内部回执有明确容量与可恢复错误，不静默丢弃未确认命令或覆盖作品。

草稿不跨账号复制。领域提交继续复核当前监护/学习授权/教师权限与活动状态；暂停、结束、已答或题目不属于冻结范围时不写入。SQLite/PG的实际并发、重开及冷恢复均核对同一行为。内部命令字段从题面读取和家庭可移植记录中剔除；删除沿用原活动/儿童关系，不能引入恢复复活路径。

## 3. 前端保存、冲突与离线

诊断与每日训练共用按账号、活动类型/会话、题目和冻结版本限定的保存控制器。每范围串行提交，输入可以继续变化，未发出的连续修改合并成最新稿；当前未确认命令保留原答案、修订、时间和请求键。已有较新本地稿时，旧回执只结清对应命令，不能显示整个作品“已保存”。旧范围的网络返回、录音与绘图事件不能改新题内容、提示或忙碌状态。

浏览器缓存只保存自己的作答与待确认命令，不含令牌/私有评分键。刷新先读取当前授权和服务端状态，再展示恢复；存储不可用或已满时明确提示，保留内存稿并提供下载。离线输入保持可编辑，恢复网络后核对原命令；停止等待不宣称撤销服务端提交。切题/退出/暂停在可保存时结清当前稿，否则要求保留本地副本并明确选择继续，不能仅清掉防抖计时器就丢掉最后800ms输入。

冲突不自动以任一方覆盖另一方。保留/下载本地副本后读取服务端稿，显示两个版本的时间与范围；明确选择继续编辑的版本后再按新修订写入。尚有未确认首次提交时先核对该提交，不能把同一题当成全新未答题重新上传或改变独立首答。

## 4. 首次提交与训练订正

点击提交时冻结完整命令（答案/不会/跳过、耗时、请求键及必要草稿修订），并锁定当前输入。提交前处理当前保存队列；存在其他页面冲突时先解决，不静默采用另一份稿。v2提交可绑定草稿修订，服务端在同一事务核对；已升级草稿不能由缺少栅栏的旧请求绕过。

同一提交丢回执、停止等待或刷新后，先读取实际活动/首答，再用原命令核对。同键异参明确冲突，成功后读回真实下一题/反馈/完成状态；恢复不能新增第二次首答。结构答案比较使用稳定JSON语义，SQLite与PG对象键序不改变重放结果。旧首答的评分、耗时、提示、曝光和独立性保留；不改变已有评分规则来让测试通过。

训练“再想一次”由学生明确开启新一次订正，生成新命令身份；显示原首次表现与参考思路接触事实。缓存丢失或读取旧会话不能伪装成独立首次成功。暂停/恢复、提前结束、题面失败与不会/跳过维持原有测量边界。

## 5. 17种输入与表达

逐项覆盖单选、多选、判断、数字/分数、文字填空、公式、多空、表格、配对、排序、分类拖放、图上选点、几何绘图、分步表达、作答图片、简答、录音。复用现有渲染、控制图形、MathLive、StudentMedia及评分服务，不把项目文件直接作为诊断媒体，也不执行学生表达式或代码。

每类核对：有意义的不完整草稿→保存→刷新恢复→继续编辑→首次提交→真实反馈/待复核→历史读取。可替代键盘操作的题型不强迫拖动；排序保留按钮、分类保留下拉，绘图保留文字表达，录音保留选文件。绘图活动笔迹、题面资源失败和公式编辑状态按冻结题目隔离。正在录音/处理媒体不能误提交空答案；离开释放录音轨、计时、播放器、Blob和请求。

题面图片/音视频、缺配置和无法呈现的结构不生成“不会”或错误能力结论，允许明确跳过与反馈。图片/录音/绘图等需要人工判断的输入继续待复核，不因有文件、非空文字或自动化完成而给予正确分。真实设备录制、读屏与教师量规核对仍为独立门禁。
