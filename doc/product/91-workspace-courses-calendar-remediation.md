# 课程列表、课程详情与日历整改

日期：2026-10-23。对应用户提供的三张 HyperKnow 截图。本轮同时整改页面和可执行流程。

## 问题分析

原实现的主要问题并非单个按钮样式，而是页面之间没有统一状态。

1. **课程列表**：独立成人教学课程没有进入“我的课程”；课程卡、最近学习和课堂入口分散。没有一致的搜索、进行中与已完成筛选，缺少可信的阅读进度。
2. **课程详情**：使用另一套窄导航，与课程列表割裂。学生课程与成人课堂的目录布局不同，学习、练习、资料和单元的返回路径不完整。学习目标只在悬停时出现，手机端无法直接查看。
3. **地址与状态**：切换页面只更新 React 状态，没有同步地址。刷新可能回到首页，返回键与课程单元不一致。恢复地址之前切换学科，还可能覆盖原来请求打开的日历。
4. **日历**：原先主要是事件清单，缺少月历、周历、选中日期、跨月移动，以及确认、编辑、完成、重开和批量删除流程。
5. **数据与权限**：日程缺少编辑版本控制。批量删除需要先校验全部目标，避免越权或部分删除；订阅与计划事件不能作为普通手动任务修改。
6. **交互细节**：移动导航与旧顶部偏移冲突；工具菜单没有锚定输入框；弹窗缺少键盘焦点约束和焦点归还。视频无语音导出时会重复关闭 AudioContext。

## 本轮实现

### 统一工作台

- 课程列表、课程详情与日历共享侧边导航；手机使用横向五项导航。
- 当前页面、学生与学科写入地址。课程单元、资料/练习面板、日历日期与月/周模式可以刷新恢复。
- 请求按加载代次接收结果，防止旧档案请求覆盖新选择。切换学科先清除旧视图数据。
- 课程创建对话框、日程详情、删除确认、连接来源与新建任务支持焦点约束、Esc 和焦点归还。提交期间收到的 Esc 在提交结束后执行。
- 无学习档案、无课程结果、无学习历史提供清晰说明与可操作入口。

### 我的课程

- 接入现有社会学课程，未创建学生档案的家长也能直接学习。
- 重建票券式课程卡、封面区域、进度条、下一讲和右侧周学习记录。
- 搜索、全部/进行中/已完成、周记录切换均执行真实筛选。
- 学生课程“继续学习”直接进入下一段已审核课堂；保留独立测量入口。
- 学生课程阅读进度只来自当前账号的课堂会话。家长与学生的私有学习记录不混用。
- 周记录按已读微课最近学习日期统计，不等同于学习时长或能力提升。

### 课程详情

- 统一课程封面、策划信息、简介、三面板、单元列表、讲座时间线、逐课学习与练习、项目和核查布局。
- 学习目标改为可点击详情，手机同样可用。
- “获取帮助”进入相应课堂并带入学习目标提问草稿，由用户确认发送。
- 课堂进入使用浏览器历史；返回目录、前进恢复、刷新继续、保存退出与原单元恢复形成闭环。
- 课程学习返回时带回学生、学科、单元和面板。
- 阅读完成与知识掌握保持区分；课堂题、辅助作答与独立测量不合并为虚假的掌握率。

### 日历

- 月历按实际月份生成 4–6 周格，周历显示 7 天；支持上一范围、下一范围、今天、日期选择和刷新恢复。
- 左侧日期摘要、当日待办与已完成；格内展示时间、名称和完成状态，全天和跨日事件覆盖相应日期。
- 手动安排支持新建、编辑名称/标准/时间、移到待处理、确认、完成、重开和删除。
- 批量选择仅覆盖当前日期范围的手动安排；删除前明确确认，取消保留原数据。
- 学习计划通过原计划接口更新并保留版本控制；订阅事件只读。
- 保留 ICS 导入、订阅、导出，以及可展开的学习计划与同步管理。
- 新增 `POST /learning/studio/calendar/events/:id/update` 与 `POST /learning/studio/calendar/batch-remove`。编辑校验 `expectedRevision`；拒绝无权限、订阅和计划事件的普通编辑。
- 重放创建响应也移除内部创建者、请求哈希和请求标识。

## 还原边界

这轮依据用户截图复建布局与交互，仍不能称为原站 CSS、字体和资产的 100% 复制。课程封面继续使用工程自己的 SVG；图标、品牌、教学内容也使用本项目资产。没有获得或宣称获得原站私有源码。参考中的付费、代币、邀请推广、Marketplace 仍按用户要求排除。

日历仍绑定学习档案；未建档用户有明确建档入口。ICS 是互通格式，不等同于原生 OAuth 或学校双向成绩回写。与前一轮相同，题目内容覆盖和动态教学还原范围见 [白板与练习交付说明](90-classroom-presentation-refinement.md)，本轮没有把导航修复表述为全部题型与全部教学内容已完成。
