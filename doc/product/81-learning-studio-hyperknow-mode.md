# 独立学习工作台：HyperKnow 式入口与整合

## 目标

HyperKnow 的界面长处是低干扰导航、课程与学习 Feed 连续、课程蓝图先预览、讲解与练习同屏衔接。本批新增 `/studio`，先提供一套独立的同构工作流，同时把 StudyAgent 的测量、指导、复测、教材来源与安全图形讲解嵌入其中。

像素级对齐的是信息密度、留白、左侧导航、顶部上下文、圆角浅底卡片、课程单元层级和底部输入区。品牌、图标与课程内容均使用自有资产，不复制对方品牌素材或课程正文。

## 门户结构
- Home：Craft Courses 与 Instant Assistance 双模式、课程输入区、可视化/练习/主动学习入口、当前课程与下一活动。

## 已实现

- `/studio` 作为独立入口，并从主导航和首页可直接进入。
- 课程从已确认学习范围的发布原子生成；蓝图先预览，确认后持久化。
- 课程详情包含 Learn、Practice、Project、Exam，并链接回现有知识评测。
- Learning Feed 复用到期复测、待确认计划、未完成评测与证据缺口。
- History 保存课程创建与活动开始记录。

课程生成使用确定性结构而不是复制第三方课程：先按知识领域分单元，再为每个原子提供学习、独立练习和综合验证，并按指纹防止未审阅蓝图被替换后创建。Instant Assistance 使用现有助教接口；可视化只渲染已审核教学卡中的受限分数条 schema。
