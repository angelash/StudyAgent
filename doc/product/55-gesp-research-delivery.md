# GESP C++资料补充与独立教研轨道交付

2026-10-20，接续 `046cba3` 的258点、6,974题小学课程基线。用户确认此前的另一项任务已经完成，要求补充资料、同步内容与文档后本地提交。本轮保留小学三科、学习范围、学生历史、评测和指导路径，以独立认证轨道接入GESP。

## 已交付的教研能力

管理员与教师从 `/admin/gesp` 查看8个认证等级的114个候选知识点及1～4级15单元教学衔接草案。题目可按等级、场次、题型、来源、题面关键字和知识点候选做SQLite服务端分页检索；单题可查看提取题面、未审核参考材料、知识点候选、原卷页码、PDF哈希及来源。家长和学生身份在全部GESP路由返回无权限；原始资料和答案不进入小学课程包。

实现文件包括 [共享契约](../../packages/contracts/src/gesp.ts)、[API服务](../../apps/api/src/modules/gesp/gesp.service.ts)、[控制器](../../apps/api/src/modules/gesp/gesp.controller.ts)、[专项测试](../../apps/api/src/modules/gesp/gesp.integration.test.ts) 和 [教研页面](../../apps/web/app/admin/gesp/page.tsx)。数据入口见 [资料说明](../../resources/gesp/README.md)，接入边界和后续验收见 [集成交接](../gesp/integration-handoff.md)。

## 来源与内容

CCF官网真题目录两页已全部遍历，保存28个网页和131份官方PDF（106原卷、16解析、8样题、1考纲）。另固定公开仓库 `jonaslgtm/gesp-exam-questions` 的提交 `91cf8868cdbe1cd7cdec29868eb1ddf85556b6b6`，补存3份镜像PDF，来源身份保持“public_mirror_not_official”。

108个实际场次等级组合现均有可用材料：105个正确官网原卷、2个官网解析补充、1个公开镜像补充。2024年9月四级由镜像补得27题，编程题为“黑白方块”和“区间排序”，官网缺链没有改写成已恢复官方来源；2023年9月五级官网错链仍隔离。用户提供的11道非官方练习与官方、镜像及样题分别保存。

机器索引共3,132题：2,916历年和216样题；单选1,740、判断1,160、编程232。各项分别保留官方原卷、官方解析、公开镜像、样题身份、原卷SHA-256、页码和提取定位。1,070道客观题答案符号没有从机器文本恢复，需查看原卷；232道编程题中230道有参考材料，隐藏测试数据未收集。所有这些题目仍为待逐题审核研究资料，`approvedAtomIds` 全为空。

114个候选点覆盖官方69条详细标准，含170条候选先修边；1～4级49点已组织为15个单元。单元分别记录可观察目标、讨论问题、数学准备、独立检查与证据周期。认证等级不映射成小学年级，题目与机器文字计数也不计入6,974道原创教学任务。

## 验证证据

新增8项GESP专项测试通过，覆盖未登录、家长/有效学生身份拒绝、等级与来源边界、分页与SQL特殊字符、答案和本地路径不进入列表、镜像答案依据、单题恢复、损坏哈希拒绝、PDF字节校验、无索引/过期索引状态，以及49个初始点各覆盖一次。默认全仓回归为579项通过、0失败、6项PostgreSQL专项按默认配置跳过。

`npm run lint`、`npm run build` 通过；Web生产构建生成 `/admin/gesp`。离线校验核验162份网页/PDF来源、164,011,235原始字节、1,487页提取、3,132条单题载荷与来源偏移，以及69条标准、114点、170边和15个教学单元，结果见 [validation.json](../../resources/gesp/validation.json)。

`restore_archive.py --offline` 从已有原始文件重建提取和单题载荷，`build_runtime_index.py` 通过SQLite完整性检查并以7份版本化输入哈希拒绝过期索引。使用隔离合成管理员、临时业务库和真实API页面完成“黑白方块”检索、镜像标识、单题题面、递推知识点、教学衔接查看，并检查360px与768px布局。浏览器自动化注入元素引用时产生一条开发模式hydration告警，页面数据与操作仍正常；该告警未作为生产零控制台错误证据。

原始PDF、完整文本、单题载荷、只读索引和截图位于被Git忽略的 `data/gesp`，约1.64亿字节，须独立备份；Git提交只保存来源清单、哈希、提取元数据、候选内容和恢复工具。已有文件离线恢复通过不代替新环境从备份恢复演练。
