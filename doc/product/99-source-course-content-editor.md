# 资料课程完整教学稿编辑与复核

2026-10-24，实施前规格。关联 XP-B02/B05/B06、XP-E04、XP-F03/F05、XP-J03、XP-K06。

## 要解决的实际问题

资料课已能生成、审阅蓝图并进入课堂，但当前只能修改标题和目标。真实默认模型样本曾出现分数换算讲解与提示错误；用户即使发现错误也不能修正文。因此需要能核对并编辑完整教学稿，同时保护答案、版本、旧课堂和来源证据。

## 使用体验

仅候选的创建者能显式进入“编辑讲解与练习”。进入前说明会看到练习答案；共享孩子和其他监护人不因此取得草稿答案权限。正文、提炼板书、例子分步、误区与纠正、迁移、总结、练习题干/四选项/正确项/解释/两级帮助，以及来源页与短引文都可编辑。课程概览可见且可编辑，不要求用户操作 JSON。

沿用现有课程页的白色稿纸、细边线和蓝色操作；按课时与教学环节编辑，随时对照冻结原文。桌面保留来源区，手机按段阅读，控件和底部保存不遮挡内容。长稿不一次堆成无法定位的表单；错误指出课时、环节或题号，能回到对应输入。

保存整份候选是一次事务，保存成功后重新审阅再确认。未保存改动在课时/环节切换时保留；离开、后退或刷新有保留提示，可导出本地副本。服务器冲突、断网和丢失回执不能清空本地内容；读取服务器状态不自动覆盖编辑稿或更新其保存基线，用户明确放弃后才读入新稿。

## 数据、权限与发布边界

增加创建者专用教学稿读取和候选内容修订接口，使用共享受约束结构，不向普通课程目录、课堂读接口或隐私 portable 视图附带私有答案。读取返回当前内容和原始生成稿的独立副本，不公开请求回执或其他账号记录。原始生成稿保持不变，修订记录保存修改内容与版本。

修订必须携带 expectedRevision 和 requestKey。相同请求重放同一结果；同键不同命令、旧页面、已确认/已归档课程、来源变化和撤权均拒绝。整份稿通过结构、引用存在性、选择题选项及答案位置等检查后才写入；不逐项保存半份错误稿。HTTP JSON 请求保持有界，完整六课稿不能因默认过小的请求体上限被意外截断。

确认仍绑定最新 fingerprint，旧确认不能发布新稿；新课堂冻结修订后的课文和答案。已确认课不原地改写，需另建候选；原课堂快照保持原文。编辑、用户确认和 AI 自检都不登记为教师审核，不改变正式能力测量资格。

## 验收

后端使用隔离 SQLite 验证完整讲稿/题目/帮助/引文修订、原始稿不变、原确认失效、新课堂按修订答案评分、私有答案隔离、越权与撤权、已确认拒改、无效内容整份回滚、同键重放和不同命令冲突。覆盖六课有界请求与非法体积，不使用真实家庭数据。

浏览器验证编辑数字与答案、跨课/环节切换保留、来源对照、保存反馈、刷新恢复已保存稿、丢失保存回执、旧页面冲突保留输入、导出/离开提示和普通课堂答案保密。1440/768/390 截图与键盘焦点人工核对。修改确定性编辑流程不需要再次调用付费模型；新模型质量验收另保留。

本批不把手工编辑等同通用数学验证、教师审核、全教材覆盖或完整课程包生命周期。长来源按课生成、模型语义复核、完整教材映射、运行期生图及真人教学验证继续按总账本推进。
