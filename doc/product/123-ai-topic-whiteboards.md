# AI自由主题白板：受控写稿、复核、确认与独立入口

2026-10-26，实施前规格。基于122开发归档e4fd525，先提交本规格再实施。接续[计划105](105-development-plan-status-and-next-milestones.md)M1、[122逐句播放](122-whiteboard-video-sentence-playback.md)、[113可靠助教](113-durable-assistant-conversations-and-history.md)和[120独立核查](120-source-course-independent-unit-checks.md)。122完整回归/精确CI/运行交付继续自己的门禁，本增量不得混入其验收代码。

## 1. 当前缺口和结果

当前工作台makeWhiteboard只把studentId/subject/prompt发给同步preview；LearningService选择当前范围内教学卡或套用通用模板，composer中选中的modelId没有进入白板写稿。没有孩子档案的成人也不能从这一入口生成自由主题白板。122已解决逐句呈现和媒体机制，不能据此把模板称为任意主题AI教学。

新增`/studio/whiteboards`独立入口，并从工作台白板菜单提供明确链接。用户选择本人成人主题或有权限的孩子、孩子学科与已确认范围，填写主题和目标、选择现有常规模型，明确生成候选；服务端持久写稿、AI复核和原模型信息，用户读完整稿后显式确认保存，再用122播放器阅读/朗读/导出。原教学卡预览继续提供实际已有能力。无模型、无范围或生成失败均给明确原因，不暗中切回模板或另一模型。

本增量交付AI文字讲解、完整要点、对照表和公式的原文/可访问呈现。真实生图、复杂交互图形和全部HyperKnow原资产逐状态差异继续作为M1剩余批次，不因本增量自动完成；图片接入须复用现有真实生图任务/技能、私有引用和撤权清理，另先归档具体增量。不得放置假生图按钮或用装饰插画冒称教学图片。收费、Marketplace、学校原生OAuth/机构对接仍排除。

## 2. 复用资产和身份边界

复用现有XiaojiuModelsService目录、XiaojiuChatService.structured、持久tasks/租约与heartbeat、原命令回执、账号/学生权限、删除账本、双库恢复、122只读呈现单位和统一媒体时间表。默认渠道deepseek-v4-flash，显示DeepSeek V4.1 Flash；每个候选冻结实际模型，不把Auto或当前下拉框当成历史模型。实际范围只含本人选中的已确认学科/年级、原子目标和已审核教学卡，不夹带其他孩子、家长私聊、正在评测的答案或无关历史。

成人模式无需虚构孩子或学科，使用ownerUserId和真实空studentId/subject。学生身份只能自己的孩子模式，不得创建成人候选；家长按现有绑定，授权教师仍按现有正式对象授权，不建立学校租户。孩子候选在确认前由原作者私有，确认后的孩子白板按该孩子当前权限共享；成人白板只对本人可读。是否允许继续，始终核对当前账号/绑定/学生入口版本，不凭知道ID或指纹取得正文。

原StudioWhiteboard及旧存储/指纹保持。新增StudioTopicWhiteboard作为明确的AI产物，不把成人空档案塞入旧必填studentId协议；播放器读取公共的标题/scenes/fingerprint等字段，通过明确产物种类选择相应读取/旁白授权路径。新增记录可含原作者溯源，公开投影剔除内部授权、私有原始模型上下文和跨账号信息。

## 3. 契约、冻结和内容校验

新增topic-whiteboard共享契约：创建输入、原命令/版本栅栏、候选状态、模型/复核摘要、确认输入和已保存白板。输出3～8幕，标题/要点是提炼内容，narration是完整教学讲述；每幕包含学习意图及可选概念正文、最多6条完整要点和一种表格/公式展示，不用逐字拼出板书。画面标题编号与实际旁白分开；内容不得包含模型伪造的供应商任务ID、媒体URL或来源资格。

表格使用有界headers/rows和完整单元格，校验列数、空表、行数与总文本预算；公式保留原LaTeX和说明，对不支持/无效表达明确显示可复制原文，不能吞掉公式或把渲染成功称为数学正确。可访问阅读提供完整表格/公式/讲稿；Canvas对照表按整行呈现，必要时分成完整子页，导出不得靠切掉后半行解决排版。公式侧栏优先复用已有KaTeX，视频中可读原式与解释；精确排版/复杂公式导出若未满足须据实留缺口，不能声称原站像素一致。

模型不决定可信来源、资格、任务状态、归属、durationMs或指纹。服务端规范化并限制总文本，使用原JSON Schema与独立运行时语义校验；核对原文要点是否确实出现在对应旁白、步骤是否完整、引用仅来自已冻结教学卡。只读呈现及估计时长由122算法派生；指纹覆盖版本、完整场景/表格/公式、实际模型与冻结输入摘要。相同模型重试不能改成当前模型；旧原稿/原AI复核分别保留，AI修订另有原始/结果指纹。

孩子内容不能超出明确选择的教学范围而仍宣称符合进度。成人自由主题无已核对教材或外部原文时明确为AI生成候选，不伪造来源。AI复核只检查完整性、内部矛盾、数值/条件、表述适龄与不确定点，输出pass/revised/uncertain及具体问题；不把AI复核标为教师审核。确认保存需用户明确知晓AI生成，保留teacherReviewStatus=pending和formalMeasurementEligible=false；讲解/播放/保存不写掌握度、独立首答、评测结果或学习完成。

## 4. 持久状态与接口

拟新增两个领域集合：studioTopicWhiteboardDrafts保存本人冻结输入、写稿/复核检查点、版本、原命令与任务关联；studioTopicWhiteboards保存确认后的不可变白板及来源候选ID。不修改旧studioWhiteboards内容。新增schema16及双库索引，准备键在owner范围唯一，同一候选只确认出一个白板；原确认/取消/重试回执绑定本人、动作、输入摘要和原候选。

接口归入独立TopicWhiteboardController：

- POST `/learning/studio/topic-whiteboards/preflight`：只读校验当前模式/范围、实际模型可用性和输入预算，不创建任务。
- POST `/learning/studio/topic-whiteboards/drafts`：显式准备，冻结输入及实际模型，持久排队；相同本人原键只返回原候选，改题/范围/模型拒绝复用。
- GET `/learning/studio/topic-whiteboards/drafts`：本人有界分页/检索，所有候选保留真实状态。
- GET `/learning/studio/topic-whiteboards/drafts/:id`及`/requests/:requestKey`：当前权限下读取原候选与原操作回执，剔除内部授权。
- POST候选的`cancel`/`retry`：显式控制，绑定revision/generation/taskVersion；取消允许同代后台领取/检查点自然前进，拒绝未来版本、跨代、更新控制及终态，重试仍严格比较版本。旧控制回执不得作用于新代次。
- POST候选的`confirm`：仅ready且原内容/复核摘要匹配时保存，原确认重放返回同一白板；uncertain仍展示具体问题并要求明确确认候选性质，不把内容升格为正式教学。
- PATCH候选的`content`及GET候选的`history`：原作者在ready时明确修改标题、讲述、要点、表格/公式；比较原revision及contentFingerprint，原修改命令可恢复重放；保留修改前后的完整版本和本人操作，不覆盖AI原稿/原复核。历史有界分页，不能只保留最后一份。修改使旧AI复核变为非当前，界面不沿用旧pass；确认仍明确为待核对候选，不把手工改稿变成教师审核。进行中、取消中或已确认的候选不直接改写。
- GET `/learning/studio/topic-whiteboards`及`/:id`：本人成人白板或当前孩子权限下已保存白板，冻结内容只读。
- POST `/learning/studio/topic-whiteboards/:id/narration/:sceneId`：复用122逐句版本/指纹/unitId协议与语音目录，合成前后重新授权；不接受任意旁白正文。

HTTP错误区分无身份、不可访问、原命令冲突、版本变动、范围/模型不可用与暂时服务失败；读取不把正在写稿误报ready，不泄露其他作者是否存在。旧前端/旧白板接口保持兼容；新成人白板不会被旧孩子接口按null选中或泄露。需要额外字段/行为时先补本规格再实施。

## 5. Worker与恢复

使用明确任务kind及独立worker。状态queued→generating（writing/reviewing）→ready或failed；取消经cancelling→cancelled，保存是独立显式动作。任务冻结owner、mode、child/accessVersion、scope/atom版本、原modelId和上下文摘要；每次claim、heartbeat、写入检查点、AI返回、确认与输出流再次核对当前对象权限和原代次，迟到结果不得落到新候选或已删除账号。

写稿检查点原样保留；进程重启只补缺失复核，不自动再写已完成稿。显式重试延续原输入/原模型，新代次使用CAS，拒绝跨账号、错误正文和不匹配版本；取消应终止实际CLI子进程树，不能只停轮询。失败原件/受控错误分类保留，不向前端回显可能含代理凭据的底层stderr。不同app实例的同键准备和确认需事务/唯一约束保证一次产物。

删除孩子会清理其新候选、已保存白板及活动引用并取消任务；关闭账号清理本人成人内容和私有候选，另一监护人仍有权的孩子已保存白板按现有共享保留规则处理。删除账本和恢复门禁认识新集合，不得从旧备份复活已删除私稿。schema15回退备份必须与旧编译产物一致，不能用旧程序打开新增schema16；发布前另做完整可回退快照，严禁把真实环境和家庭备份推送。

## 6. 前端实际旅程

新页面先确认真实身份。无孩子默认本人成人主题；有孩子可明确切换，切换模式/孩子/学科取消旧读取并卸载私有稿，不悄悄把成人主题记到孩子。表单含主题、教学目标、有限长度、模型及可用性，预检准确反馈；显式生成后显示排队/写稿/复核、取消、失败原因和原模型重试。停止等待和取消生成分开。

生成原命令、候选定位和确认命令按账号/范围独立恢复，保留原文字及模型；网络/存储异常不清空全文，提供下载原稿/继续定位。刷新只读恢复真实任务；旧响应不得覆盖当前编辑/另一候选。完整原稿、复核问题、表格/公式可键盘阅读，确认前不隐式创建正式白板。确认超时先查询原回执，再允许原键重发，不制造重复活动。

候选的完整讲稿支持显式保存修改，布局字段提供真实编辑控件，原稿/AI复核可对照阅读；本机未保存全文按本人/候选/基线版本隔离恢复。迟到保存不能覆盖后续输入，冲突保留原全文并可下载/重新比较；已保存发布稿只能新建候选，不原地变更历史白板。手工改稿后的AI复核过期状态明确显示，用户可保留待核对性质确认，不虚构再次AI复核已经发生。

已保存列表可重开冻结原稿，进入122播放器，逐句/语音/文字/导出及已知秒数续播沿用明确产物种类。播放不把AI来源或审核状态藏进开发术语，说明仅包含用户需要判断的“AI生成、待内容核对”。外部课程平台链接、原CSS/font/DPR及声音差异不据新页面自动消失。
