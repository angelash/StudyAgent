# HyperKnow 课程教学体验：观察、需求与实施计划

观察时间：2026-10-23；入口为用户已登录并打开的社会学概论课程。仅通过可见页面、可访问性快照、播放控件及截图观察，未访问私有接口、认证存储或站点源代码。

## 已核实的教学组织

- 课程有五单元：社会学视角、文化与自我、不平等、制度、越轨与社会变迁。每单元三个讲座、每讲座四个微课，共15讲、60微课；各单元穿插社区案例研究阶段任务，并以综合考试收束。
- Learn 与 Practice 并列。Learn 进入独立白板课堂，Practice 进入逐题作答界面；不能把打开页面或看完讲解当作掌握。
- 已实际播放第一微课“社会学想象力”的部分讲解：目标导航、个人与历史两个分析层次、两个圆的关系图。右侧逐句历史与底部字幕同步，白板内容累计出现，图示在讲到相关位置时插入。
- 图示通过可见的 `about:srcdoc` 子文档嵌入，观察到韦恩图。不能由此推断其任意代码运行器、后端执行沙箱或生成模型的具体实现。
- 顶部浮动工具条提供缩放、翻页、分享、设置；右侧对话区可调整宽度。设置包含六种风格音色、0.5–2倍速、手写/标准字体、点阵背景、重播引导。静音允许继续阅读，暂停后可继续；离开前确认并保存断点。
- 新手引导覆盖连接状态、笔记分享导出、音色倍速、静音、语音打断、立即停止、对话历史。语音输入可选择关闭；课堂无须强制麦克风权限。
- 已进入“定义越轨”的练习页，核实单选题、Check/Skip、倒计时速度奖励和懂课程但不直接给答案的助教。没有代用户提交答案。
- 经动作确认后向首课发送匿名的继续学习请求，实际观察到比较表、阶段奖励和老师提出的匿名情境判断题；该奖励在没有提交判断答案前已出现，因此本项目的观看里程碑只表示讲解完成，不写为能力掌握。原站停下来等待学习者解释理由，本项目也在课堂检查点停讲，等待作答或主动继续。

## 当前工程差距与目标

现有课程主要是单元目录和测评链接，白板是另一个视频入口，缺少持续的教学会话。新增统一教学课堂：左侧点阵白板、右侧老师逐句讲解与插问、语音与书写共用一条时序；课程目录直接进入课堂。采用自有教学内容复现可观察的组织和交互，品牌与现有学生测量记录继续使用StudyAgent。

社会学课程作为独立的成人课程实验室，整理60个主题的概念、例子、误区、检查点，五个项目阶段和单元练习，提供完整导航。其阅读和练习记录只属于课堂轨道，不写入小学诊断或伪装为校准后的掌握。现有已审核小学教学卡复用相同课堂组件，保留独立测评入口。

## 实施顺序与验收

1. 固化五单元、15讲、60主题结构，编写自有讲解、关系图、区分题和项目量规。保留观察来源与逐项覆盖状态。
2. 增加服务器会话与断点：账号/学生权限、内容快照、乐观并发、聊天持久化、答题反馈和项目草稿；重启后恢复，不泄露未作答答案。
3. 还原目录卡片、状态圆环、Learn/Practice双入口与独立全屏课堂；实现累计白板、字幕、缩放翻页、可调整对话宽度、七步引导和移动端切换。
4. 复用MiniMax/OpenAI语音与小九全模型目录。以音频结束驱动教学步进，静音保持时序；暂停、停止、插问立即中止播放与待返回请求，恢复时从原断点继续。失败可明确切到文字继续。
5. 为计算例子增加隔离JavaScript Worker与代码编辑/运行/停止。禁止联网、访问DOM与顶层页面，设置超时和输出上限；这是自有补充能力，不宣称已还原HyperKnow的代码沙箱。插问由模型返回经过校验的标题、要点及关系图数据，补写白板并关联对应对话。
6. 验证越权、历史恢复、无标准答案泄漏、答题重试与内容指纹；浏览器验证课堂入口、逐步播放、暂停恢复、设置、插问、代码运行/停止、练习反馈及手机布局。截图对照可见参考；实际音轨生成与播放单独留证。
7. 构建生产服务并由现有PM2守护重新启动，归档已完成与尚未观察的项目；不以单张截图或构建成功声称全部像素一致。

## 证据限度

仅实际播放首个微课的部分内容，未逐课听完60节、未观察所有题型或最终考试成绩页。浏览器工具不能直接捕获站点音轨做听感对比；音色描述与播放控件已核实，原站合成供应商、实时语音传输和生成源代码未知。后续交付须区分可用实现、视觉对照与外部尚未验证行为。
