# 课堂代码实验、输入与草稿恢复

日期：2026-10-25，实施前规格。接续[课堂规格107](107-classroom-turns-and-reference-state-parity.md)和[里程碑105](105-development-plan-status-and-next-milestones.md)的M1/M2，对应XP-D05/D06、C01、K02/K05。先归档提交，再实施；本批只完善已有JavaScript课堂实验，GESP C++真实课堂融合继续保留独立范围。

## 1. 当前问题与目标行为

当前CodeWorkbench只在组件内保存代码；切换白板页、离开或刷新会失去修改。没有输入区，运行前把超过16000字符的代码静默截断；错误、停止、超时和正常结束都只有日志字符串，没有明确状态。代码应成为课堂里可以修改、输入、运行、解释和恢复的实验。

学生打开已经显示的代码块时看到原始示例或自己已保存的草稿。代码与输入按账号、会话和确切块隔离；切换页和刷新恢复，不覆盖其他孩子或另一冻结课程版本。编辑立即在当前标签页保留，后台保存明确显示保存中、已保存、仅本地和冲突。保存失败不会清空编辑区；主动读取远端或以当前远端版本再次提交本地内容，不静默覆盖。

## 2. 数据与API

新增独立`classroomCodeDrafts`业务集合，绑定ownerUserId、studentId、sessionId、stepId、blockId与原代码摘要。保存code、input、revision、updatedAt与必要幂等命令摘要；不保存执行权限、答案键、凭据或服务器路径。旧会话没有草稿时只投影原示例，不伪造历史。

GET查询当前已曝光代码块；PUT/PATCH保存绑定expectedRevision、稳定requestKey、原代码摘要、code和input。请求键相同且内容相同先重放；同键异参409；并发编辑以领域事务依赖判冲突。当前授权、原会话和原代码块仍须存在；未来未展示节点不可读取或写入。完整代码最多16000字符，输入最多8000字符，超限明确拒绝，不截断。最多保留必要的近期命令回执，已保存内容通过一般备份恢复。

儿童/账号的关系导出和真实隐私删除包含草稿；可移植导出去除内部幂等、授权与技术摘要。不把草稿、运行次数或stdout当独立测量、评分或掌握证据。课程更新继续使用冻结会话对应的旧示例。

## 3. 浏览器执行与交互

继续使用具有独立CSP的Worker，不创建服务器执行接口。代码只在学生主动点击运行后执行，输入是本次运行的固定文本快照；提供`readLine()`与只读输入行，不通过网络取数据。超时2秒、最多100行/20000字符，禁止网络和再启动Worker；停止/卸载立即终止，旧运行晚到消息不能覆盖新运行。

正常完成、运行错误、超时、手动停止和加载失败分别显示。超长代码、过量输入和不支持情形在执行前说明；不能把被截断程序当成完整运行。修改代码不自动执行。运行中的编辑形成下一次草稿，不改变正在执行的快照；需要重跑由学生明确选择。

原始示例、当前代码、输入和输出清楚分区；保留常规复制、重置示例、停止和运行按钮。重置是显式操作，覆盖前允许取消或恢复当前草稿；不会重置课堂答案或学习进度。键盘操作、窄屏换行和编辑区高度必须核对。静态打印保留原教学示例，个人草稿导出另作明确标识。

## 4. 验收与边界

双库验证草稿重开、同键/异参、并发冲突、账号/孩子隔离、未展示块、原块变化、真实隐私删除和备份恢复。浏览器验证编辑/输入/运行、页面往返/刷新恢复、弱网与冲突、长文本拒绝、运行错误/超时/停止、旧消息拦截、390/768/1440视口和键盘；网络、DOM、import与无限循环保留现有隔离回归。

以课程里的真实示例和合成输入运行验证，不能因代码能运行就宣布教学内容正确、学生掌握或C++路径完成。HyperKnow原站当前需要重新登录，未观察到的具体输入/编辑细节继续保留参考缺口；本批实现不声称100%像素或行为一致。
