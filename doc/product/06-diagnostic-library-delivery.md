# 知识诊断与题卷库阶段验收

2026-10-19，持续目标进行中。本文件记录已经运行的范围，不替代 M00–M10 的完整验收。

## 已实现

- 原子知识图与先修无环校验、学习范围版本；组卷保存范围、题目、量规和映射快照。首次作答不可覆盖，草稿和服务端提示分别记录。
- 数值与分数等值、多选、排序、多空等确定性评分；主观题保留待复核，人工重评有独立版本。
- 按独立题目、题族、提示和时间衰减估计掌握与区间。未知、证据不足、迁移和延迟保持分别显示；这是规则估计，尚无标准化常模。
- 理解/执行、先修、迁移、保持假设与支持/反证；新题验证、预算内指导、确认/暂停、1/3/7/14 日复测及可比性复盘。
- 四步真实 API 页面：学习范围、答题恢复、知识证据报告、计划和复测。初始原创基础材料为 44 个点、1,129 道规则可核验练习，**不代表一至六年级完整课程覆盖**。
- 本地试卷索引：72,468 份卷、885,203 条题目；结构完整 19,056，部分缺题 23,470，PDF 29,942。结构完整、可评分、媒体可用、来源许可、教研有效性独立审核。
- 教研原始资料和家庭发布库隔离；分页检索、缺题占位、参考答案、收藏、打印、版本发布与撤回。HTML 清洗，媒体来源与本地清单双重校验，按试卷授权，PDF/媒体支持 Range。
- 助教改为当前孩子的范围、证据、计划和本会话历史；取消每次联网子进程。无 key、超时、非法引用等情况下使用本地指导；可取消，按主体限制并发和日用量。
