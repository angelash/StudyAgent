# 152 工作台统一入口与学习对象基础批次

日期：2026-10-30。接[150统一执行计划](150-integrated-delivery-plan-and-work-ledger.md) R1及[151对象边界协议](151-workspace-context-and-independent-overview.md)。本页记录首批基础实现，R1和全部开发目标均继续进行。

## 实现范围

- 根布局只保留一个持久导航宿主。复用原240/60侧栏、Satoshi/MiSans字体、选中态、弹窗和手机抽屉焦点；六个原入口加任务、诊断、报告，底部按角色显示档案、设置与教研管理。
- 登录默认进入`/studio`；支持校验后的同站点活动返回。旧`/learn`、家长看板和知识入口显式转入工作台，保留合法对象和原会话定位，保留矛盾参数供错误恢复。
- 首页继续保留课程创建与即时帮助，吸收已有真实主要下一步，移出重复统计看板。成人创建课程提供原有私人资料建课路径，无需创建孩子档案。
- 新任务区复用原今日训练；诊断、报告、知识与周记录分开定位。已完成会话进入报告，验证预览进入诊断，同一指导计划进入任务区；来源报告可返回。报告读取不恢复待提交答案，不将未完成会话变成作答页面。
- 新档案区只读`/learning/students`元数据并保留原建档契约，授权、学习码与设备仍使用原功能。账号与数据管理归底部入口。
- 独立概览由服务端明确隔离孩子课程、知识、计划、资料、白板与日历；学生学习码不能进入成人模式。页面按账号卸载私有状态，迟到响应受请求代数和对象校验约束。
- 学习对象缓存由取回有效档案的页面保存。侧栏不保存尚未验证的URL选择；重新选择使用显式空选择，防止无权限旧地址在导航时再次覆盖缓存。

课程、题包、会话、原首答、草稿、曝光与报告/计划ID沿用原服务。本批无schema变更；原72项状态保持11 implemented / 50 in_progress / 11 planned / 0 verified，WS仍按150逐项跟踪。

## 验证和证据

验证使用主目录内独立源码、数据库、端口和Web产物。不同批次分别记录，不合计通过数；原始失败和trace本地保留，版本化证据不包含Cookie、令牌或私人学习资料。

最终结果和源文件哈希见[证据回执](../evidence/2026-10-30/workspace-r1-foundation/receipt.json)。第五轮42项浏览器检查通过，另一次16项兼容旅程通过，均无跳过、重试或flaky；二者不拼成一次整站回归。合同、配置、API与隔离生产Web编译通过，1861项应用输入与冻结副本一致。

接口批次36项通过，包含21项既有内存夹具、6项真实SQLite首页检查、5项真实SQLite工作台检查及4项纯导航检查；同样5项新工作台检查在实际PostgreSQL 17.11中通过，含重启恢复和学习码撤权。不能将内存夹具写成双库验收。

第一轮浏览器11通过/2定位失败，第二轮13通过，第三轮39通过/3失败，第四轮40通过/2失败，第五轮42通过，各轮输入与结果分别保留。API第四轮错误套用了内存reset夹具，21项未能执行正确业务检查；PG第四轮启动钩子超时、21项pending，均未计为通过，后改用独立HTTP持久夹具复验。详细原因、首次结果和复验见证据回执，原始trace留在本地QA目录。

设计册同步到当前候选源码：134项功能、459个当前HTTP入口都有源码定位，706份引用文件、4429条文档链接和10项离线浏览检查通过。此项只证明文档、静态索引与离线浏览器自洽，不是整站功能验收。

本批仍未发布：正式API/Web构建保持原版本；业务SQLite只读核对仍为schema24/revision187。现有QA PostgreSQL服务继续保留，仅使用本批独立schema，不操作其他QA数据。
