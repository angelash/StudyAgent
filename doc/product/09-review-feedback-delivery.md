# 量规复核、反馈与权限闭环

2026-10-19 阶段交付。对应 M01、M05、M06、M09，完整产品目标继续执行。

## 已实现

- `reviews` 模块和 `/admin/reviews`：按学科、状态、评测/训练及分页读取复核任务。列表只含任务所需摘要；详情读取作答当时冻结的题目、量规、参考响应、提示/接触记录和全部评分版本。进行中的评测不开放复核详情。
- 分项量规逐项记录达到程度和作答依据，服务端按冻结权重计算总分。遗漏/重复量规、伪造总分、错误权重均拒绝。没有分项量规的历史任务保留有理由的人工总分复核路径；量规损坏不能降级绕过，但仍可查看和处理反馈。
- 评分采用 expectedVersion 和 requestKey：重复请求不产生第二个版本，旧版本不能覆盖新评分，同一请求标识不能改写成另一份内容。首次响应和原始判分不变，评分修订追加保存。
- 训练评分修订进入练习反馈、总结和错题读取，不进入掌握度估计。原始提示级别、首次/重试和参考接触记录保留。已结束训练可以回看各题及复核结果。
- 评测回答重评后，当前和后续使用过该证据的报告均追加新版本，原报告可展开追溯。历史报告仅使用其完成时以前的回答和假设状态历史，避免后来成功倒灌早期报告；后续独立新题验证成立仍能保留 resolved 状态。
- 评分纠正后不再有有效失败支持的旧假设标为 withdrawn，保留撤回原因及历史；不将改分称为已验证的学习改善。保留样本不足、置信区间、题族和维度边界。
- 评测报告加入确认范围快照、教材课时名称快照、未覆盖课时提示和评分版本入口。
- 学生报告、练习反馈、错题均可提出评分/题意/显示/作答环境反馈。反馈所有权从真实作答推导，禁止传入其他学生绕过权限。open → investigating → resolved/dismissed 各步保留版本、说明和操作者；反馈不自动改分。
- `/parent/access`：教师复核授权与撤销、一次性监护人邀请/接受、反馈处理记录。教师评分权限由监护人单独授予，教师身份本身不提供全体孩子数据，也不自动获得档案/学习管理权限。
- `/admin/accounts`：管理员核实注册账号后授予教研/运营身份，修改时重新核对管理员密码并保留审计。版本冲突拒绝；变更角色/状态撤销该账号旧会话，教师停用或身份撤销同时撤销既有复核授权。当前管理员不能撤销自己的权限，保留可用管理员。响应和审计不保存密码。

## 边界与继续实施项

本阶段没有把人工复核包装成自动作文、口语或图片能力评分。附件/听说任务、17类题型完整输入与校验、可靠导入/OCR/模型任务、持久outbox、细分学生学习身份、计划调整与受影响证据提示、业务数据导出/删除、并发与PostgreSQL及部署恢复继续按完整计划实施。真实教材映射和足量独立题族/迁移/保持资源仍需继续补齐，不能以已有题数代替课程全覆盖。
