# 平均数分母选择的原子诊断计划

2026-10-20，接续阶段49，沿用完整需求与 M00–M10。此计划须先单独归档并本地提交，再实施；不能由本轮新增一个子点宣称完成全部原子化。

## 目标与观察边界

四年级平均数综合任务已经分别保留数据个数、总量、平均值及合并分组记录。总分失败不能直接说明哪个步骤有问题。本批定义“明确平均对象并把零数据计入份数”的独立子点，归属于平均数，隔离计数对象/分母的选择，包含有明确范围的零记录和未参加记录。综合题分项只作为独立核查线索，不能直接增加子点掌握度、题族、根因支持或样本。

新增48道独立原创任务：核对把参与但为0的记录排除的主张；明确范围的记录计数与分母表达；从实际记录表区分参与0与明确未参加；在同一记录中按问题指定的对象恢复人数或天数。每种12题，理解、过程与两种迁移结构分开，有零与非零对照，不用题目编号或固定选项位置决定答案。缺失、未参加、未记录、0不能混为一类；信息不足时不编造平均数。

教学卡明确可观察行为、适用对象、反例、替代解释、独立核查和保持要求。分母选择通过后仍可能有合计、除法或记录问题，不能将此点通过等同于整个平均数掌握。
