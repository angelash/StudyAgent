# 单课时资料课程的独立核查

2026-10-26，实施前规格，接续[120](120-source-course-independent-unit-checks.md)、[计划105](105-development-plan-status-and-next-milestones.md)与M1/M2内部学习可用性。先提交本规格，再实施。120的独立候选仍须先完成自己的整站回归、精确CI与守护交付；本增量在独立工作区实现，不改动正在验收的120候选。

## 1. 使用缺口

资料课程规划允许只有一课，但120的核查要求选择至少两课。因此一课课程有已确认讲解和来源，仍不能准备新情境核查。内部学习常从一小段材料开始，本增量让一个明确课时目标也能形成独立练习组。仍是来源课程的教学核查，不取得原子知识正式测量资格，不凭一组正确率推断稳定掌握或深层原因。

## 2. 输入与兼容

核查选择范围从2～6课改为1～6课，空选择、重复ID、越界ID和超过6课继续拒绝。单课仍必须active且已确认，有稳定目标和完整、确切可引用的冻结来源，完整context不超过18000字符；不能用重复同一课凑够两课，不截断原文。新旧选择继续使用source-course-check-v1配方，现有2～6课定义的输入、字段、顺序、规范化摘要和持久指纹不变；没有集合、索引或schema迁移。

只有明确选择的目标进入冻结输入；生成4～8道新情境single/multiple题，保持两级提示、完整正确集合与逐项理由、每题目标/引用对应、全部目标覆盖、规范化精确排重和来源完整性核对。一个目标对应多个情境不代表已经得到多个独立题族，界面继续标记待内容审核、formalMeasurementEligible=false。持久写题/复核、原模型重试、取消、发布指针和未曝光确认等协议不变；同文跨定义作者曝光继续生效。

## 3. 交互

准备弹窗显示选择1～6个课时，选中一课即可预览和显式准备；未选择时禁用。只有一课的课程无需特殊分支或隐式选中，仍由本人确认范围和模型。预览准确显示1个覆盖目标和未覆盖课时数，题组确认后进入原逐题课堂、冻结来源、首答与复盘；不创建第二套练习状态机。归档/撤回后旧记录、原命令、本机稿及身份卸载沿用120。

## 4. 验证与交付

纯校验覆盖单目标完整来源、4道不同题覆盖同一目标、零/重复/七目标拒绝，并确认原双目标冻结摘要不变。真实HTTP在SQLite/PG走单目标准备、模型替身写题/复核、未看答案确认、逐题作答与来源读取，不生成正式能力事实；原21项HTTP和原生恢复继续回归。浏览器用明确的一课合成课程，从勾选唯一课时、预览1目标、生成、确认到首答和刷新恢复。默认DS另做合成原文小调用，技术调通与教师质量审查分别记录，失败原件保留。

先取得120整批与运行结果，再合入其最终归档；本增量按适当全量、精确CI及可回退守护流程单独交付。每次推送前核对上一轮CI已终态，不取消运行中的CI。不做计费、学校原生OAuth/机构对接或Marketplace。
