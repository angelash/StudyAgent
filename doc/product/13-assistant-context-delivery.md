# 助教真实题目上下文、提示计量与会话恢复

助教现可绑定当前评测、练习题或指导计划。服务端验证学生、学科、学习会话和题目归属，不能用任意引用取得其他资料。练习使用开始时冻结的活动与题目，评测使用当时的范围。草稿、当前提交状态和已知知识证据按需组成上下文；评分答案、参考解析、判分配置不传入模型。暂停计划和撤销绑定在再次使用时拒绝访问。

同一账号、角色、学生、学科、页面和具体题目恢复同一段对话。切题后分开保存，最近50条可读；后台历史不因此删除。提问使用请求键，重放返回已保存回复，不重复对话、提示或AI记录，不同内容复用请求键拒绝。迁移3新增会话范围及消息请求键唯一索引，旧无键历史保留。

获得题目帮助时，帮助记录与回复在同一事务提交。未提交评测的助教只提供确定性学习提示，不让模型生成该题解答；学生未绑定题目的聊天也仅给通用引导。练习可使用模型的下一步提示，非法引用、检测到答案泄漏或不当结论时回落到规则。后续首次响应按实际提示记录计量，不能继续标为独立完成；已提交响应不会被后来聊天追改。取消且未提交的回复不留下部分对话或帮助记录。自由文本模型输出过滤仍有语义局限，不代表数学/语言内容已获得教研准确性认证。

前端已接每日练习的当前题、评测当前题、报告和计划。打开时恢复会话，切换学生/题目/身份时取消旧请求并阻止旧结果覆盖。显示提示记录和规则/AI建议来源；调整手机宽度、滚动高度、输入标签和展开状态。由于本轮 Browser Runtime 的终止结果，新增交互和响应式画面仍待浏览器核验。
