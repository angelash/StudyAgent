# 项目附件、文件产物与冻结提交

日期：2026-10-25，实施前规格。接续[项目97](97-versioned-course-projects.md)、[资料课程生命周期110](110-source-course-revisions-and-lifecycle.md)与[里程碑105](105-development-plan-status-and-next-milestones.md)，对应XP-B03/B04、E05、K02/K05/K06。先归档提交，再编码；完整产品范围不变。110最终运行收据提交前不提交本批业务代码。

## 1. 目标与现状

项目已有阶段、文字产物、证据说明/来源链接、自评、修订说明、冻结提交、人工复核和文字AI建议。ProjectArtifact只有values与evidence，不能保留图片、文档、程序或录音；把文件名写进文字不构成真实附件。本批让学习者提交真实文件，复核者准确看到当时版本，并可在重启、备份、隐私删除与恢复后继续核对。

附件只属于项目产物，不自动成为独立能力测量。上传、打开文件和自评不代表教师批准。当前原站附件状态没有新观察，本批是内部项目能力补齐，不宣称取得原站未知状态或源码。

## 2. 文件与原件

每阶段最多20个附件引用；每份文件最多20MiB，分块1MiB。UTF-8文字/Markdown/代码/CSV正文最多1MiB，明确拒绝超长、非法编码或空字符，不截断保存。图片先支持PNG/JPEG，复用已验证解码/旋转/去元数据和像素上限；录音沿用现有WAV/WebM/Ogg/MP3/M4A实际解码，最长180秒及输出预算。PDF按实际格式解析，页数上限120；提供静态原页预览与原件下载。DOCX/XLSX/PPTX保留原件并核对有界容器身份，先提供原件下载和准确的预览状态，不把ZIP头当作已经读懂内容。

文件名仅用于显示与下载，不组成磁盘路径。上传原始字节与规范化显示文件分别保存大小/SHA/处理版本；替换文件生成新附件身份，不覆盖旧文件。代码作为可读文本或下载，不在服务器执行；项目文件与GESP隔离运行仍各自管理。格式不支持、解码失败或工具不可用时保留原草稿及可恢复操作，失败不显示空白成功预览。

复用现有媒体解码、文件租约/原子写入、持久任务、内容哈希和严格路径工具。新增项目附件领域关系，避免将项目文件伪装为某道诊断题的作答附件。业务上传/处理预算是明确运行约定，不是付费配额，也不限制已授权研究资产的迁入规模。

## 3. 上传、处理与权限

附件记录绑定真实项目、冻结定义与阶段、创建者和可选孩子。上传/处理有独立修订与任务代次，传块不修改项目文字草稿的revision。创建命令以当前账号/项目/阶段及稳定请求键重放；异参拒绝。相同块/哈希重放成功，不同字节不能覆盖已有块。刷新读取真实已传范围，重选文件时核对大小、类型与已传块，不靠文件名判断同一原件。

完整接收后以持久任务核对原件、解码/派生、摘要与文件清单。领域状态与有效任务租约同事务发布；当前用户、原监护/学习授权、项目及阶段定义在发布前复核。取消请求与真正结束分开显示，取消/撤权/隐私删除后旧worker不能发布或重建文件。临时文件属于精确任务代次，未知或仍有活读者的文件不被顺手删除。未完成上传24小时失活后按持久清理收尾，明确显示过期及重新上传入口。

学习者只能写自己的项目。家长和当前授权教师按现有项目复核资格查看学生产物，不能编辑他人草稿；成人私人项目只给创建者。项目文件读取、预览与范围下载每次重查当前权限；撤销学习码/教师资格或关闭账号后立即失效。新增路由逐条加入学习码允许清单，上传与下载不能扩成家庭管理权限。

## 4. 草稿、提交与复核

ProjectArtifact增加可选附件引用；旧稿没有字段继续读取。保存时解析当前ready附件，核对同项目/阶段和实际文件身份。提交冻结附件ID、原件/显示文件摘要、名称、类型、大小与用户说明；文件变化不能改写旧提交。新稿可移除引用，但旧提交仍引用的版本不能普通物理删除。未被草稿/提交引用的附件可以显式删除，经过持久收尾清理实际字节。

附件说明与原文字证据并列，可选择与哪一条证据/产物字段关联。阶段切换、未保存离开、原稿导出和历史提交保留现有行为。新增身份序列化显式包含文件快照，跨SQLite/JSONB键序保持一致；旧无附件建议与快照不重写或补造新版本。

复核历史显示当次提交的文件与说明，查看旧提交不会偷偷使用最新图片。量规依据可指向当前冻结附件身份；越阶段、其他项目、删除/处理中或未提交文件不能成为该次人工复核的文件依据。提交、提示和AI建议仍不写独立掌握度，也不声称已经验证深层原因。

## 5. 界面与AI建议

每阶段提供选文件/拖入、名称/类型/大小、分块进度、后台处理、取消/重选恢复、失败重试与删除。文字草稿可继续编辑，不因传块反复发生版本冲突。附件ready后由学习者明确带入本阶段；未提交与已提交版本标签清楚。图片可放大、PDF按页看静态预览、文字/代码可读、录音可播放，Office文件提供原件下载。窄屏显示完整状态与说明，操作有键盘焦点和触屏尺寸。

网络中断、掉回执和主动停止等待保留原命令；刷新可读取相同上传/处理任务，不偷偷再传一份。离开时回收浏览器Audio、Blob与请求；跨账号/项目/阶段的迟到响应不能换掉当前文件或草稿。

本批沿用项目文字建议，明确列出其依据为已保存文字、证据和附件说明。原始文件字节不在后台自动送入模型，不能声称AI已经看过未提供的图片、PDF或录音内容。项目请求先核对完整序列化上下文预算，超预算保留作品并明确选择范围，不将截断文本当完整作品。完整多模态文件研读和持续AI建议任务属于后续AI闭环，保留在整体目标中。

## 6. 导出、删除、备份与恢复

项目JSON/可读作品导出包含同一提交的文件清单与真实引用。家庭可移植导出带入当前允许的原件、规范化文件和必要预览，并剔除内部请求/租约/暂存路径，不包含其他成人私人项目。原件和显示件可独立校验。

新增关系接入SQLite/PG持久化、备份引用提取、冷恢复、删除账本、暂存回收、文件只读审计和导出文件清单。已有备份不能复活已删除儿童或账号的文件；共享孩子的合法提交和文件继续保留，但已撤回授权不能复活。数据库提交前不物理擦除，提交后可重启收尾，恢复程序核对所有实际文件而不只统计记录数量。

本批保留全部引用运行文件的字节，不以软链接或索引代替备份。研究资产总迁入与独立备份仍在M5逐项对账，项目附件完成不代表整个资产库已备份。

## 7. 验收

协议与双库覆盖真实传块/重放/异参、多个阶段、并发编辑/上传、原件/派生摘要、原稿和历史提交、权限/撤权、取消/重启/旧worker、坏格式/超限与缺工具、文件读取/范围、账号/儿童删除与共享保留。真实解码PNG/JPEG、PDF、UTF-8/代码和常见录音；Office容器验证与原件打开检查单独记录，不伪造预览或教师阅读。

浏览器用合成文件跑上传→说明→保存→提交→新文件修订→旧版复核、刷新/丢回执、重选续传、取消/重试、放大/分页/播放、阶段/身份切换、键盘和390/768/1440。实际打开导出，SQLite空根冷恢复、PG保存/恢复与最新删除账本验证字节；真实手机相册/录音、读屏、教师与连续教学继续各自验收。所有失败和范围限制入最终收据，未满足门禁不标全部完成。
