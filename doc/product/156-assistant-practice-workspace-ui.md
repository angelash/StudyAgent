# 156 对话练习安排与本人作答工作台

日期：2026-10-30。实施前规格，接[150总计划](150-integrated-delivery-plan-and-work-ledger.md)R2和[147](147-conversation-practice-guidance-and-review.md)第24、27～29节。先提交本规格，再实施应用。唯一main及主目录内隔离验证继续适用；历史独立worktree描述不再作为当前操作要求。

## 实际基线与实施顺序

已核对现有候选创建/读取/编辑/原键查回、共享安排、逐点开始、原生作答/理由/帮助/完成接口。工作台任务页尚无共享安排列表，助教只有笔记/白板入口，通用作答hook只支持answer-draft-v2，不能直接承接包含独立learnerExplanation的assistant-practice-answer-v1。

R2第一批接完整审核题UI，复用现有持久服务，不增加HTTP地址、业务集合或schema迁移。后续继续安排撤回和成人/AI持久练习；本批不展示虚假的撤回按钮、成人开始能力或生成成功。当前任一批通过均不关闭R2、原72/WS或R3～R8。

## 来源、候选与明确安排

AssistantWidget每条已保存消息增加“安排练习”，工具栏增加“对话练习”。面板复用WorkspaceDialog、笔记/白板的来源选择、原文与字体、工作台控件；支持最近/更早消息及搜索，完整选择最多20条，不因分页删掉未显示的原ID。

受众必须是明确有权的孩子和学科；原对话已绑定孩子时固定原对象，未绑定时由监护人明确选择，学生仅本人。读取已确认scope及原子定义，只展示该范围内的1～3个目标。原教学、档案和确认范围的年级分别显示，不能自动调整档案、借用数学范围或忽略来源冲突。预检显示完整来源、字符预算、未曝光审核题覆盖和实际阻断原因；生成审核题候选、保存说明、安排分别明确操作。

私人候选可编辑标题/教学说明，读取完整原生题面；参考答案单独展开。家长预览不代写孩子曝光。学习码作者在私人候选中看过审核题干的影响必须沿实际服务语义核查，不把预览后的题称为陌生独立测量；本批仍全部isTeachingOnly。共享安排只含原服务合法教学投影，不带origin、私聊、模型prompt或内部来源路径。候选与安排均沿原版本/完整命令/原requestKey恢复，丢回执不能换键重复创建。

## 学习任务与原活动

新增任务页内的“对话练习”视图，规范地址为`/studio/tasks?view=conversation-practice&studentId=…&subject=…`。打开原安排增加assistantAssignment；打开已开始的组增加assistantPractice及question。拒绝不一致别名、重复参数和另一孩子/学科/安排/活动；从实际服务结果核对身份后才注册导航。列表、安排和本人活动均不借用正式指导planId。

家长可读取合法共享预览和原训练历史；真正开始、草稿、首答、帮助与完成只给当前学习码本人。每组显式开始且始终返回原两题活动，第二、三组继续原安排，不因第一组合法曝光重新选题。首答和首次理由保留，订正单列；提示、查看参考、家长示范分别明确记录。答案未明确提交前不展开反馈；反馈、原回执及后续编辑分开显示。完成组后回到原安排继续下一组。

题面/输入复用QuestionRenderer、原17题型、公式、图表及现有真实图片/音频媒体目标。媒体上传未完成、题面资源损坏或输入工具不可用时阻断提交并保留全文，不把一个链接当成已恢复附件。教学首答、使用帮助、待复核与正式能力证据分开呈现；不能用首答正确率或完成勾选推断掌握。

## 完整副本、命令与并发

新增仅本机assistant-practice-workspace-copy-v1，绑定owner、实际对象/学科、原会话/候选/安排/组活动/题目。准备阶段保存完整选择、教学目标、目标点、标题说明与原pending创建/编辑/安排命令；作答阶段保存原答案、独立理由、server baseHash/revision/attempt及原pending草稿/回答/帮助/完成命令。二者不复用普通answer-draft-v2键，也不把理由塞入StructuredAnswer。

每标签独立副本；刷新恢复本标签祖先，其他副本显式比较，采用前另存当前全文。存储失败先下载完整副本才能切题、切对象、离开或后退，beforeunload保留原生保护。导入严格校验格式、大小、账号与原对象身份，不自动提交或创建活动；媒体内容继续依赖真实服务端原件，JSON副本中的媒体引用不表示原件已下载。

草稿仅由本人明确保存或明确提交前保存；刷新、导航和打开副本本身不自动写入。服务端保存返回原确认revision与当前revision，发生并发变化时保留双方并比较。重试只重放原完整命令；结果核对后可保留后续编辑，但新提交必须使用当前fence。当前评测、权限或安排状态改变时停新写入，保留合法输入；401/403清私有投影并重新核对身份。账号、对象、题目key和AbortController分别隔离迟到响应。
