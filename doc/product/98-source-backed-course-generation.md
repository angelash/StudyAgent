# 资料到课程：来源快照、生成与课堂

日期：2026-10-24。对应 XP-B02/B05/B06、XP-F05、XP-J01/J03。实施前规格，后续按实际结果追加验收。

## 完整使用流程

成人可直接粘贴分段资料或上传 PDF，不必创建儿童档案。孩子已有 PDF 可在当前授权档案和学科内选择；成人私人资料与孩子资料分别授权。复用现有 PDF 原件、OCR、公式表格恢复和页图，不另造一套识别器。文本按来源段落标识，PDF 按实际页码标识。

选择来源及具体页/段、学习目标、目标语言（沿用来源/中文/英文）和每次预算，预览被选正文与识别核对状态。限制一次生成的正文总量，超出时由用户缩小选择，不能静默截断后声称已读全部材料。当前范围内知识目标可以作为参考，但未经审核的来源映射不能成为正式测量资格。

显式生成建立可恢复任务；列表显示排队、生成、等待审阅、失败、取消、已确认与归档。刷新和进程重启恢复同一任务，取消终止本次生成，旧租约不能发布新结果。重试有版本检查；更换来源、语言或目标必须产生新生成版本，不能悄悄改写旧课堂。

生成后先显示课程蓝图和讲解预览，包括目标、来源、概念、示例、误区、提炼板书、检查题、提示和迁移。用户可修改课程名称、目标与课时标题/目标、删除不需要的课时，再确认建课。重复确认恢复同一门课；来源在等待期间更新时必须重新核对，不确认过期预览。

确认后的资料课程进入实际课程目录和既有课堂：按句讲解与语音、逐项板书、插问、课堂练习、提示与断点保存。每课来源引用能打开当时选定页/段的冻结正文，并可查看原始 PDF 页面。新生成练习只作学习反馈，答案与提示私有保存；它们不会进入小学正式能力测量或自动获得教师批准。

## 数据与约束

资料增加明确的账号所有权；无孩子的资料使用真实空 studentId，不伪造档案。孩子资料继续每次检查当前访问权。资料课程独立保存 owner、可选学生/学科、输入、正文快照、来源摘要、目标语言、模型、生成任务、候选内容、确认/修订/归档记录和请求回执。

模型仅接收选中的授权正文与目标，返回受约束教学对象。每课至少一处引用必须对应实际选中的来源页和可在该页找到的短摘录；伪造引用、无效页码、缺少完整教学结构、非法题目/提示或任意可执行脚本均不能成为可确认课程。生成内容标明待教师内容审核；确认表示用户愿意用于学习，不等于学科正确性已审核。

所有正式课文和课堂冻结自己的版本。后续 OCR 重做或资料修订不替换旧课文；当前来源状态与冻结来源分别显示。课程归档阻止新的课堂启动，已有课堂仍能读取自己的快照。资料/课程纳入学生及账号隐私导出与删除；删除后在途任务不能重新写回内容。

## 质量与验收

使用隔离 SQLite 与匿名材料，验证成人无需档案、孩子权限/撤权、文本和 PDF、来源预算、真实页码/短引用、生成取消/重启/重试、并发旧租约、候选编辑失效、重复确认、来源更新、旧课堂恢复及私有答案隔离。浏览器走通选源→生成→审阅→确认→课堂→练习→返回原页的完整路径，覆盖1440/768/390。默认小九模型做真实小调用，失败保留可重试状态。

本批不将资料课替代正式教材映射和教师内容审核；跨全教材的课时覆盖、所有学科的有效生成、真实学生教学效果与参考平台全状态像素比对继续保留总目标。不得以单个生成样本或结构验证声称全部完成。
