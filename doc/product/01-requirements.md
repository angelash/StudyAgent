# StudyAgent 完整产品需求基线

版本：1.0，2026-10-19。状态：开发基线。授权：先完整分析和归档提交，再开发；充分迁入已有资产，不以体积缩减范围；持续实施到全部验收。

## 1. 产品定位与结果

为小学一至六年级语文、数学、英语建立可解释的学习诊断与指导产品。学生知道“我学到了哪里、哪一步还不稳、下一步做什么”；家长能区分知识缺口、方法障碍与尚未证实的原因；教研和运营能把试卷资产变成有来源、有质量依据、可测量的学习材料。

系统围绕知识点而非刷题数量组织数据。知识点须拆到可独立观察和干预的粒度。一次综合题可含多个点，但不能把整题得分平均复制成每个点的真实掌握度。系统既描述表面表现，也生成可证伪的深层原因假设，通过对照题、前置点探针、表达和复测增加或减少证据。

“实际能力”在产品中指指定课程范围、指定测量时间下可观察到的表现及其不确定性，不把学习测量包装成人格、智力、医学诊断。没有证据就显示未知，不能用 AI 叙述补齐。

## 2. 人群和关键流程

- 学生：选择或确认年级、教材、学期、已学单元/课时；短时分组答题；获得友好且具体的解释；继续训练并观察进步。
- 家长：建立孩子档案、授权绑定、安排时长；查看知识地图、证据和待验证原因；确认指导计划；观察独立性、迁移与保持。
- 教研/教师：维护知识图、量化指标、题目标签、评分协议、评测蓝图和验证组合；审核内容与诊断规则；处理主观题复核。
- 运营/管理员：管理来源、入库、媒体和模型、长任务、质量、权限、审计、发布及回滚。

首次路径：注册登录 → 创建孩子 → 选择年级/学期/教材版本 → 确认已学范围 → 查看本次评测覆盖与预计时长 → 分组答题并保存 → 结果、证据与未知区域 → 验证任务 → 指导计划 → 今日训练 → 间隔复测 → 前后对比和复盘。

回访路径：恢复未完成评测或今日任务 → 查看到期复测 → 阅读前次干预效果 → 调整下一周计划。没有题目、进度不明、断网、AI 不可用、题目有争议时均有可完成的替代流程。

## 3. 账户、数据与授权

- **AUTH-01** 注册与登录显式分开，凭据哈希保存；管理员通过受控引导创建，账号名称不能决定权限。限制失败重试，错误信息不泄漏账号存在性。
- **AUTH-02** 会话有有效期、撤销和退出；Web 使用安全 Cookie 或受限短期令牌，避免持久化高权限令牌；更改权限可使旧会话失效。
- **AUTH-03** 孩子归属由创建者及受控邀请确定；知道学生 ID 不构成绑定授权。邀请有接收人、有效期和一次性消费记录。学生使用受限学习身份。
- **AUTH-04** 所有学生、会话、答案、报告、AI 消息、附件接口执行主体隔离。教研/运营按职责授权；公开检索不能返回草稿或标准答案。
- **AUTH-05** 输入严格验证，CORS 配置白名单，附件与 HTML 清洗、媒体访问控制、速率限制、敏感日志脱敏、操作审计、数据导出与删除均可验证。

## 4. 学习范围和原子知识体系

- **SCOPE-01** 档案包含年级、学期、各科教材版本/册次、已学课时/知识点、当前进度日期、每次时长；支持不同学科学习进度不同。
- **SCOPE-02** 课程进度形成版本快照。已学、在学、未学与补基础分别表示；变更后旧评测仍使用旧范围，不倒改历史。
- **SCOPE-03** 题目选择严格遵守范围。追溯前置点须明确标记“基础核查”；不能以题量不足为由悄悄使用未学内容。
- **KG-01** 以“概念/操作 + 可观察行为 + 条件 + 达标标准”定义原子点，支持领域、父子、先修、易混淆、迁移关系。先修图有向无环，版本可追溯。
- **KG-02** 每点有教学说明、常见表现、错误编码、验证方式、难度梯度、课程映射和示例。数学包括概念、步骤、计算、表示和应用；语文包括字词、句意、信息定位、推断与表达；英语包括音形义、词汇、句法、听读和表达。
- **KG-03** 题目与点的映射区分主测点、前置点和次测点，注明权重和可观察步骤。自动标签是候选，教研确认后才成为高信度测量依据。
- **KG-04** 跨教材共享概念、教材内顺序与版本差异分开保存；不能按同年级假定同进度。图谱可搜索、编辑、导入、校验并比较版本。

## 5. 评测、量化和深入诊断

- **ASSESS-01** 初始、单元、阶段、微测、错因验证、延迟复测均有蓝图，明确范围、原子点、认知维度、难度、题量、时长、停止规则和覆盖缺口。
- **ASSESS-02** 按年级和已学范围分层组卷，先基础锚点再分支验证。覆盖不足可缩减并明确未测区域，不能生成无依据的全能力百分比。保留蓝图与题目版本、选择原因和随机种子。
- **ASSESS-03** 分组作答、断点恢复、自动保存、提交幂等、跳过/不会/未作答区分、暂停及终止。首次独立作答、提示后作答、重复尝试是不同证据。
- **ASSESS-04** 支持 17 类现有协议的真实交互：单选、多选、判断、文本、多空、数字、分数、公式、匹配、排序、分类、竖式、分步、作图/手写、口语/音频、组合等（以共享契约为准）。复杂题保存步骤与附件；不支持的题型不能假装自动判分。
- **ASSESS-05** 客观题确定性判分，支持容差、分数等值、多空逐项、无序集合及单位规则；主观题依据量规逐步评分，低置信度进入复核。空白不得转换成数字零。
- **ASSESS-06** 同一题的重复提交不能累计成多个独立样本；重复同型和提示降低证据权重。题目争议或答案变更可重评，生成新结论版本并保留原始证据。
- **MEASURE-01** 每点展示掌握度、证据量、置信区间/可靠度、最近测量时间、状态（未知/学习中/不稳/待巩固/稳定），并按理解、执行、迁移、保持、独立性等维度拆解。
- **MEASURE-02** 单次正确率与长期掌握度分开。时间、正确性、步骤、提示和表达均需足够证据方可解释；作答慢只表示观测到耗时，不能直接推断注意力或能力。
- **DIAG-01** 表面问题记录事实：漏项、进位错误、信息提取错误、步骤中断等。深层原因以假设表示：前置概念不足、表示转换受阻、策略不当、迁移失败、保持不足等。
- **DIAG-02** 每个假设显示支持证据、反证、替代解释、置信级别、当前状态、下一验证题/行为与可证伪条件。只有诊断规则被验证，才可把假设标记为“支持”；尚不能解释时保持未定。
- **DIAG-03** 通过同知识点低阅读负担题、前置点独立题、同构异表题、分步对照及延迟题分辨原因。一次综合题不支持多个深层原因的确定结论。
- **DIAG-04** 报告可展开到原始题目、步骤、时间、提示和评分理由；家长可反馈异常状态和申请复核，教研可记录判定与影响范围。

## 6. 指导、训练、复测与复盘

- **PLAN-01** 指导计划由确定性规则筛选依据、AI 解释与定制建议协作产生；每个行动必须引用知识点与证据，包含目标行为、活动、题目/资源、时长、成功标准和复测日期。
- **PLAN-02** 优先修复阻断当前学习的前置点；每日总时长不超过用户预算。计划允许家长确认、暂停、调整；每次调整保存版本和原因。
- **PLAN-03** 每个待验证原因对应验证任务，验证失败回到替代解释；禁止用更多相同练习代替诊断。
- **TRAIN-01** 今日任务包含讲解/示例/独立练习/迁移/复测，渐进提示不立即透答案；首次表现、提示、修改、复习间隔可追踪，完成依据唯一题目和活动而非提交次数。
- **TRAIN-02** 错题本支持来源、标签、错误步骤、复做记录、收藏、打印与移除；按知识点聚合并与原试卷关联。
- **REVIEW-01** 默认安排次日、3 日、7 日、14 日的适应性复测，时间可调整；优先新题及同构变式，不把背下原题当迁移成功。
- **REVIEW-02** 复盘比较干预前后相同量规下的表现、样本量与不确定性，区分练习效果、独立性、迁移和保持；无足够可比证据时明确“待验证”。
- **REVIEW-03** 日/周报告解释计划完成度、改善证据、仍待验证点和下一步；家长不必理解算法即可行动。

## 7. 试卷、题目和资产全量利用

- **ASSET-01** 搬入 `rogue-prototype-lab` 学习软件调查、试卷宝服务与恢复工程中的可复用题卷、媒体、模型、工具和证据。保留完整原始快照与来源索引，不只复制示例。全部学段可保存，学生产品首期测量范围为小学三科。
- **ASSET-02** 对活跃 SQLite 用一致性备份；生成快照时间、源路径、行数、文件大小、SHA-256 和验证结果。媒体依据清单逐文件复制校验，支持中断续传；原项目不修改。
- **ASSET-03** 原始库、规范化库、已审核题库和已校准测量题分别管理。保留原 UUID、原 HTML、原答案、下载状态、缺失引用和原错误，不伪造缺题。
- **ASSET-04** 试卷模型含来源、年级、学科、地区、学期、类型、年份、结构、题序、子题、PDF、页码与局部坐标。题目含文档/答案协议/量规/媒体/知识映射/版本。原始完整、媒体完整、可作答、可评分、教学有效是独立状态。
- **ASSET-05** 建立试卷库筛选与分页、预览、整卷练习、单题练习、收藏和打印。PDF 型可查看打印但不冒充结构化自动评分；部分试卷清楚列出缺口。
- **CONTENT-01** 来源许可、媒体安全、答案协议、知识映射和审核均为发布门禁；内部研究资产可全部归档，用户端发布由单独字段控制。
- **CONTENT-02** 批量导入支持文件上传、PDF 文本/扫描识别/版面切分、题图与答案关联、候选修订、预览审核、批量发布和撤回。过程为持久任务，有重试、取消、进度、错误和幂等键。
- **CONTENT-03** 富媒体支持图片、表格、公式、音频、文章/题组和作答附件；离线本地链接可用，损坏媒体明确列出。保存清洗后 HTML 与原始材料，不渲染任意脚本。
- **CONTENT-04** 既有模型、PDF/打印、裁剪纠偏、文档处理、网页库工具评估后适配；记录文件哈希、接口、运行环境与适用范围，独立验证后再计为本产品能力。
- **CONTENT-05** 复用 11 款软件调研结论：错题标签、任务状态与历史、单题/整页导入、教材→章→页→题→答案、多维试卷筛选、分层资源、听说读材料、版本化教材目录与缓存。每项落实到可测试流程。

## 8. AI、可靠性与可用性

- **AI-01** 发送已授权的当前题目、当前作答、知识点、必要历史证据与计划上下文；限制内容与历史长度。不能仅发送页面名称，也不能依赖每次聊天联网检索。
- **AI-02** 结构化输出经 schema 验证；引用只能指向真实证据。记录供应商/模型、提示模板版本、延迟、降级和审阅。建议不得改写原始答案或直接设置掌握度。
- **AI-03** 超时、额度不足、断网、配置缺失均有明确状态和规则指导；检索按需启用，工具调用不接受原始不可信内容的指令。
- **UX-01** 学生界面专注单次活动，大触控区、清晰字级、自动保存反馈和短时分组；家长界面展示依据、程度、下一行动；运营界面高效搜索、分页与批量处理。
- **UX-02** 手机 360px、平板与桌面均可用；键盘、焦点、标签、对比度和减少动画可访问；加载、空态、失败重试、未登录与无权限均有对应页面行为。
- **UX-03** 本地中文可直接运行，无外部字体/CDN依赖；开发信息和算法参数留在教研/运营视图。
- **OPS-01** 业务数据持久化，数据库事务、唯一约束、迁移与回滚、事件 outbox、任务租约和失败恢复；重启不丢会话/答案/计划/任务，重复请求不重复计分。
- **OPS-02** 提供本地独立运行与 PostgreSQL 部署路径、健康与就绪检查、日志/指标、请求 ID、存储容量和任务积压监控。远程正式上线另按明确发布授权执行。
- **OPS-03** 可执行备份、恢复、导出、升级和故障演练；源资产快照与业务数据分开备份。
- **QA-01** 安全回归、评分与测量边界测试、用户流程与重启恢复、迁移清单核验、真实浏览器与移动布局验收、性能测量覆盖完整需求。

## 9. 服务指标和交付判据

本地参考硬件和数据规模记入性能报告。题卷检索默认 20 条、最大 100 条；不能返回全库再由浏览器分页。常规 API 目标 p95 < 500ms，目录/纸卷搜索 p95 < 1s；长任务进入队列并在 2s 内返回任务标识。AI 单独报告，不计入本地确定性判分预算。每项指标要有运行采样而非静态声明。

评分可重放：同一题目/规则版本和同一响应产生同一确定性分数。掌握结论可追溯：每条证据关联学生、评测、题目版本、作答时刻、评分与规则版本。权限负例必须通过。重启后续答与恢复演练必须通过。测量模型未做真实学生标定前应标明“规则估计”，不能声称具有标准化常模或已验证的心理测量效度。

## 10. 交付物

完整源码与迁移、可运行的学生/家长/运营产品、独立资产目录及校验清单、知识/题目数据、测试与真实运行证据、部署与恢复手册、分阶段本地提交、需求逐项验收状态。用户已有变更独立保留，提交不夹带凭据、会话数据或无关文件。

## 11. GESP C++扩展（2026-10-20）

用户已确认此前前置任务完成，并授权补充、同步内容文档及本地提交。扩展增加以下要求，不改变原52项需求的验收状态：

- **GESP-01** 建立独立编程认证轨道，认证1～8级独立于小学年级1～6和现有三科；保留来源版本与旧评测隔离。
- **GESP-02** 全面遍历公开官方真题目录、保存原始文件与提取证据；官方原卷、解析、样题、公开镜像、用户模拟练习分开标识。固定镜像版本，错链隔离，缺口显式保留。
- **GESP-03** 归纳官方大纲为可观察候选知识点、先修与数学准备；优先组织1～4级教学衔接，5～8级保留完整框架。待审候选不能当作已审核课程或学生掌握结论。
- **GESP-04** 管理员和教师可按等级、场次、题型、来源、关键字与知识候选分页查询并定位原卷；研究文本、答案和未审核映射不向家长或学生身份开放。
- **GESP-05** 学生课程须另有家长确认的编程已学范围、审核内容与题族、多维证据、提示暴露和间隔复测；完整编程评测要求隔离执行、资源限制、可信测试集及版本化评分，不能只凭样例判正确。
- **GESP-06** 原始档案与业务库分离备份，提供按哈希精确恢复、离线重建与版本不符门禁；文档、来源、知识点、题目和交付证据同步更新。
