# 证据化图形讲解与教材引用

本批把 Hyperknow 登录后观察到的“可见执行阶段、先文字后图形、来源可核对、下一步可接续”转化为 StudyAgent 可以审核的图形教学和教材引用能力。目标不是复刻它的课程内容，也不是把自由生成图形塞进学生页面。

## 已实现

教学卡现在可选声明受限的 `fraction_bars` 图形数据。首批为分数等值、异分母加法和异分母减法提供原创作图：同一个整体、统一份的大小、数相同单位的份依次呈现。渲染器只读取 `teachingVisualSchema`，不接受模型生成的任意 SVG、HTML、脚本或外部嵌入。

图形带可读文本和辅助技术标签，窄屏会纵向重排，并遵循减少动态效果的设备偏好。讲解末尾仍明确写明“看过图不等于掌握”。学生收起讲解后，要用不同数值的新题、不同结构和 D+1/D+3/D+7/D+14 复测验证；提示、看过示例和自主完成继续分开记录。

真实 Chromium 截屏见 [教学图卡运行效果](../evidence/2026-10-21/teaching-visual-runtime.png)，其 SHA-256 为 `7ae96262597b8c4749991f82ec83eced8e430d055ebcbcb35ee4531cd72863f1`。

生成指导计划时，活动会从冻结的学习范围、已审核知识点和课时映射快照生成教材引用，包括教材、版本、章节、课时和候选页码。引用同时写入活动及教学快照，后续计划回顾不会因教材目录变化而漂移。页码统一标为“页面定位候选，待教研逐页确认”，家庭不直接获得受版权限制的整本原卷。

## 关键约定

- `TeachingVisual` 只允许经过 schema 限制的分数条；共同分母必须能由每个分母等值切分，分数必须落在同一整体内。
- `LearningSourceCitation` 区分 `candidate_needs_review`、`not_located` 和 `source_unavailable`，不把来源匹配、课时映射和页码核验混成一个“已确认”。
- 教学模拟只解释一个已审核示例，不替代测评；源题、题族、评分量规和知识定义仍由现有测量闭环管理。

## 验证

- 定向内容与来源测试：2 个文件、7 项通过；其中确认三份分数教学图的数据边界，以及教材引用冻结、页码候选、缺页和越范围映射。
- 全仓 API 回归：77 个文件、712 项，706 通过、0 失败、6 项 PostgreSQL 默认跳过。
- API 与 Web 类型检查、生产构建和 210 个文档链接检查通过。
- Chromium 产品旅程 5/5 通过，覆盖手机、平板、桌面、触屏键盘、建档、评测、报告、指导计划、分数图卡、复测排期、家长记忆与教研工作台。
- GitHub Actions `39572021761` 在提交 `906a519` 上通过 application、browser 和 PostgreSQL 三条作业；远端总时长 10 分钟。

## 仍未完成

家庭自主上传的 PDF、Office、Markdown 知识库尚未开放，因为还需要监护授权、文档隔离、解析失败处理、来源页预览、删除和恢复的完整流程。当前页码候选也仍需教研逐页确认；真实学生效果、家长可理解性和教师使用证据不能在浏览器测试中替代。后续继续接入受控文件生命周期，并把图形类型扩展到更多原创、可验证的数学与语言教学模型。
