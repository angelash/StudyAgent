# 课堂按需图片、生成任务与参考图版本

2026-10-24，实施前规格。关联XP-D03/D04、XP-C03/C06、XP-J01/J03、XP-K05/K06。总范围沿用[完整体验方案](92-experience-and-content-master-plan.md)及72项需求；本文件尚不是交付声明。

## 体验目标与实际接入位置

已有课堂能展示工程内两张生成位图、受控图形和逐行表格，但图片不能随当前讲解或插问产生；`ClassroomImage`只接收`/classroom/`静态路径。资料课程虽然可以生成完整讲稿，尚不能为当前示例补一幅真实生成图。学生看不懂场景时，需要留在当前节点补图，并能继续原来的语音、板书和练习。

首批支持成人课程、小学授权课堂和资料课程的当前讲解节点：点击“补一张讲解图”，核对当前主题、用途和可选补充要求后发起持久任务。生成期间继续读文字、暂停或离开；返回同一课堂能查看任务。失败有重试和取消，成功图片先作为待核对参考候选，使用者选用后加入该课堂节点。生成本身不改变原课程、语音句号、已读状态、私有题目答案或孩子能力结果。

入口先按当前教学需求提供情境插画、概念关系说明、场景对比三类用途。已有可精确表达的受控图形/公式/表格继续可用；图片中的数量、标注和比例须核对，不能把未经核查的位图当作评分标准。所有实际生图调用走小九`aigw-imagegen`技能，不用SVG、占位图或绘图脚本冒充真实模型输出。

## 页面与交互

1. 当前板书工具栏提供文字清楚的生成入口；首次展开显示将使用的当前课题、环节和内容摘要。补充要求有长度上限，允许保持空白，系统补齐简洁教学提示词。
2. 提交只保存任务。卡片显示排队、生成中、待核对、已选作参考、失败、已取消；没有实测进度时不造百分比。普通错误说明可恢复动作，工程诊断折叠，不展示代理地址或供应商原始错误。
3. 多次点击或丢失回执恢复同一任务；生成期间禁止为同一请求重复建任务。主动“再生成一版”创建新版本，保留旧版及其选择事实。
4. 候选显示缩略图、完整放大图、替代文字、用途、实际图像模型和“AI生成，标注仍需核对”。可选用、暂不使用、删除候选；选用只代表个人课堂选择，不记为教师内容批准。
5. 选用结果绑定原环节身份。等待时切到另一页或另一课，晚到图片只出现在原节点；不跳回旧页，不抢焦点，不使语音恢复播放。
6. 放大弹窗有关闭、Escape、背景关闭和焦点归还；手机能完整看图，长说明不挤走课堂操作。切账号、离开页面时释放临时blob URL，错误重试保留当前句和本地输入。
7. 已选参考图进入对应节点的笔记/导出；未选候选不混入正式课堂笔记。图片导出需实际载入同一授权版本，离线文件带生成与待核对说明。不能仅导出一个短期blob URL。

## 模型适配与依赖

按本机集成技能的实际协议调用`get_current_env.py`，仅当`next_action=run_skill`才启动同目录的`image_gen.py generate`。不修改技能脚本，不读取登录凭据，不绕到公共服务。默认图像模型为技能默认`gpt-image-2`，与默认文本模型DeepSeek V4.1 Flash分开说明；不能因图像服务不可用而静默降到其他模型。

服务端定位集成技能目录，支持明确的运维路径覆盖；能力自检分别检查目录、Python依赖、环境注入和本地代理是否可用。缺失时提供文字课堂和可执行修复提示，不阻塞其他学习能力。个人机器绝对路径不写入共享课件、API响应或前端构建。

进程参数使用数组、`shell=false`、隐藏窗口；提示词写UTF-8文件，通过`--prompt-file`传入，输出使用任务与租约独立目录、随机文件名、显式`--out`及`--force`。首版固定有界尺寸和质量，不接受客户端路径、URL、供应商地址、任意模型或命令参数。生成同步等待CLI结束和写出产物，不把提示词文件当成成功。

设定有界执行时间、心跳和取消。记录应用任务/模型/时长及安全错误类别；不声称一次应用调用等于一次底层HTTP请求，SDK可能有内部重试。超时后不自动无限重发生成；用户重试前可恢复既有任务状态。CLI进程被取消或租约失效，即使后来写出图片也不能发布。

## 数据、权限与一致性

新增独立课堂图像记录，至少保存：owner、student、session、step、冻结讲解身份、请求摘要/回执、用途、补充要求、提示词版本及私有提示词、实际模型、任务ID、状态、生成版本、文件逻辑ID/哈希/格式/尺寸、选用版本及时间、删除事实和创建/更新时间。文件不放领域JSON；个人参考图不写进共享编译期课件或公共静态目录。

客户端请求只指定已授权课堂与当前环节，服务端重新读取冻结讲解构造输入。默认仅包含该节点讲解、已展示板书及必要来源短引文，不发送孩子姓名、完整家庭档案、未作答题标准答案、提示键、整份聊天或任意本地文件。自定义文本只作绘图要求，不执行其中指令。

开始、读取、控制任务、选用和下载都重查账号、课堂归属及当前学生权限。公开其他账号的课程不等于可读取其个人生成图。教师权限沿用已有具体学生授权，不能只凭角色看所有图片。普通学习者不能把图片选用升级为正式教材审核或测量资格。

持久任务在最终提交时用同一领域事务的租约栅栏，重新核对权限、原课堂、环节和冻结身份；候选准备与最终发布分开。文件先写任务私有暂存目录，解码校验、移除隐私元数据，取得内容哈希后才发布逻辑ID。不同租约的输出目录隔离，旧worker无权覆盖新结果。落盘后领域提交失败的暂存物由受控回收流程处理，不能扩大到原始教材/原件。

## 生命周期、导出与恢复

原图、标准化展示图和提示词清单可被同一业务引用。删除候选先提交删除事实并取消任务；物理回收须检查当前引用与保留策略，路径限定在应用自己生成的目录，拒绝软链接/目录联接。账号、学生或课堂删除联动清理对应记录和文件，恢复旧备份继续应用删除账本，不能重新显示已经删除的个人参考图。

家庭导出包含有权取得的生成记录、来源说明和校验过的实际图片字节，不输出代理、环境变量、内部请求摘要或其他账号的提示词。备份/恢复覆盖新增文件目录；仅备份数据库不算参考图可恢复。旧课堂没有新字段时仍能读取，新增能力不改变旧内容指纹和作答事实。

## 验收分层

- 适配器：真实技能目录及环境自检；结构化进程参数，含引号/换行/命令字符的提示词安全；不存在目录/依赖、401/403、超时、取消、无文件、伪文件、错误尺寸与超限文件。
- 任务和双库：排队、重启、心跳、取消、失败重试、重复回执、不同租约竞争；撤权/删账号/删课堂阻止晚到发布；不覆盖旧参考图和旧学习进度。
- 权限和文件：跨家庭、其他课堂、错误环节、被撤销学生、路径穿越、联接、私有提示词、图片下载及范围请求；元数据清除与实际解码。
- 浏览器：当前页发起→离开/刷新→恢复→放大→选用→切页→原页回看→导出；失败/取消/再生成；1440/768/390、键盘、焦点、减少动画和长文案。替身图片只证明界面与生命周期。
- 真实模型：使用匿名教学场景实际生成一张图片，按技能调用`view_image`展示并核对生成与保存链路，保留提示词、模型、产物、耗时及限制；参考图不被称为教师批准或已校准测量内容。
- 资源恢复：独立目录备份恢复后可读取已选原图；删除账本阻止复活，提交失败的暂存物可被精确回收。生产环境只做匿名健康烟测，学习写入使用隔离QA库。

## 本批之后仍需推进

插问自动判断是否补图、来源原页作参考输入、可编辑图片迭代、课件级人工审核/发布和更广图表语法继续按总账本推进。英文句点、缩写和小数的字幕分句也须专项完善，不能因为中文按句播放通过，就宣称所有语言都达到同等节奏。运行期图像与长资料分块是相邻独立任务，均不替代全教材、真人长期学习、真实设备和全状态像素验收。
