# 分项观察、原子子点与独立验证开发计划

2026-10-20，基于 `ce454f6` 的追加实施计划。总需求和 M00–M10 仍以 `03-development-plan.md` 为准，本计划不替代剩余内容和最终52项交叉验收。先归档提交本计划，再实现和验证。

## 1. 需要解决的问题

现有综合题可以冻结各空得分，但画像只有主测知识点。例如多位数除法五栏题中，“剩余十”填错会使“合并的一”跟着错，不能据后一个空认定孩子不懂十换一；完整商正确也不能掩盖前面过程错误。现有主测画像、先修假设和指导计划应继续使用真实独立响应，不将一个综合题复制成多个样本。

首个完整实例为 `atomic:math:divisionregroup`：已给定剩余十和原个位，把余十换成一并合并，保持未分总量。父点为 `foundation:math:divisiondigits`，先修为 `foundation:math:placevalue`。该实例交付可复用的分项观察协议与完整学习闭环；其余复杂知识点仍需逐个拆解、编题与审核。

## 2. 数据与测量边界

- 新子点有独立目标、成功标准、教学卡、两种基础和两种迁移题族，共48道原创独立题。给定余十避免把除法表执行混入子点测量；包含零余十或零个位的边界。预计用时是编写预算，不是速度常模。
- 审核映射增加可选分项绑定，声明评分键、必须先达标的上游键、子点及审核依据。首版限定为有确定性分项评分的多空协议，绑定同科、已定义的直接子点及父点先修；键缺失、重复、上下游重叠或未发布目标不能批准。服务端绑定子点定义指纹，保留映射修订。
- “合并的一”对应子点，“剩余十”是上游条件。上游未达标时显示需要先核查上游；提示、曾曝光、未评分、跳过和暂时不会分别保留限制，不产生独立能力结论。分项观察永不进入子点掌握估计、题族数或根因的支持计数。
- 评测冻结分项目标定义和映射，报告可追溯当时的评分键、条件与子点；当前画像须比较当前定义，旧定义不能静默用于新判断。独立验证沿用进度授权和题组预览，不能自动把未学子点加入已学范围。
- 独立子点响应进入已有样本、区间、迁移、保持、假设和指导机制。保持真实间隔和掌握门槛不变；分项线索不能直接升级为“已查明深层原因”。

## 3. 关系与存量升级

父点增加子点先修，采用明确冻结的第二份原创关系发布清单。原有混合运算清单字节不变。新清单保存父点旧/新完整定义、48道已编写综合题的完整内容与原映射哈希；12道五栏题额外绑定上述步骤。

关系迁移泛化为多个显式发布，保留原导出和历史测试。仅精确未编辑v1（有卡或无卡）及具备已知系统补卡谱系的v2可升级；未知历史、教师编辑、草稿和映射候选继续保留。仅冻结清单内内容和映射未变的题可以重绑。新安装的初始映射也必须匹配清单明确列出的哈希，不能宽泛批准同点旧题。定义、映射、修订与真实事件共同事务回滚，重启幂等。

旧题内容、历史报告、进行中会话保持；旧定义证据退出新定义的当前估计。历史预览及旧计划继续使用既有冲突/重新确认机制。

## 4. 实现顺序与产品入口

1. 归档并本地提交本计划。
2. 冻结当前父点和综合题清单，新增子点、原创教学及四种独立题族，接入种子与关系发布。
3. 实现共享分项绑定协议、服务端审核校验、冻结定义和确定性观察计算；保持与独立测量管线分离。
4. 在报告和展开证据中显示具体步骤、上游限制及验证建议；从报告进入独立子点题组预览。教研可以查看和维护绑定，学生界面使用学习语言。
5. 通过正式身份完成综合题线索→独立子点作答→知识估计/先修验证→指导计划→到期复测与复盘。无模型时已有规则指导可用。
6. 独立验证后归档交付证据，完成本地分阶段提交；不推送。

## 5. 验收与回归

- 逐题独立重建48题答案、全部干扰项、合法错答、零边界、协议和时间预算；历史5438题内容与ID保持。
- 分项表：目标成功/失败、上游失败而下游跟随、提示、曝光、未评分、暂时不会、重评分、缺失或重复评分键、不同目标定义。一个综合题不增加任何子点样本或独立题族。
- 映射门禁：不存在/不属于本协议的键、非直接子点、不同科、未发布目标、重复绑定、并发旧版本、已变更题面；审核绑定子点指纹，存量编辑不覆盖。
- 两份关系发布同时存在时，各自升级与幂等；未知版本、补卡谱系、编辑保护、候选保护、故障注入整体回滚；原混合运算专项继续通过。
- SQLite与PostgreSQL正式HTTP、真实持久化和重启验证；未开先修时范围拒绝、预览确认、主体隔离、独立题去重、子点估计、先修对照、计划与复测。保存历史报告并在定义/评分变化后核查可比性。
- 默认回归、PG实机、API/Web构建、全仓类型检查、当前课程结构审计。性能仅报告当前本机实测。

浏览器动作仍受此前 `BROWSER_ACTION_OUTCOME_UNKNOWN` 的硬阻断约束，本阶段不能用HTTP、服务端渲染或本地图片冒充浏览器验收；其恢复需要新的用户指令。教材映射、剩余测量素材、当前候选跨环境复验和最终52项验收继续，不能将本阶段通过标为总目标完成。
