# 持续课堂插问、讲法调整与参考状态对照

日期：2026-10-25。实施前规格，接续[主计划92](92-experience-and-content-master-plan.md)和[里程碑105](105-development-plan-status-and-next-milestones.md)的M1。对应XP-C01～C06、D01/D02/D04/D05/D06、K01/K02，相关课程导航XP-B03/B04继续保留。先归档提交，再改业务；不因先做插问而删去视觉、声音和完整教学要求。

## 1. 当前明确缺口

当前课堂已经支持逐句音轨、逐项板书、暂停、节点插问和补充笔记，但浏览器每次发送临时生成新请求键。服务已保存、回执丢失后再次发送可能创建另一轮问答；中途刷新也没有可检查的当前插问身份。服务器在检查重放前判断消息上限，最后一轮成功的回执可能无法重读。

插问内容虽然携带已展示讲解，但没有清楚区分“换个例子”“说简单一点”“补先修”“对照表征”；教学上下文未冻结到确切句/节点。暂停、回答播放、补充板书和回到原课需要显式的同一轮身份与恢复位置。已有几何截图校验并没有构成HyperKnow的全部状态矩阵，不能表示100%像素还原。

## 2. 可恢复的一轮问答

客户端在用户确认发送时创建稳定请求键，绑定会话、当前题/节点、讲法、问题和固定选型；失败后保留同一命令，成功后才清除。修改问题、讲法、题目或节点使未提交草稿成为新命令，不能悄悄用旧键发送另一份内容。不得把其他账号、孩子或会话的草稿带入。

发送之前暂停课堂并停止当前/预取音轨，等待已有进度保存队列，再确认可恢复位置。服务端冻结当前环节、字幕版本/单元、提问时的展示范围及实际问题；客户端不能指定任意未展示节点或别人的题目。幂等重放先于消息上限与新调用资格检查，已提交的相同请求读回原轮次，不再次调用模型或重复补板书；同键异参明确409。

需要保存的问答轮次应是独立、可授权查询的状态，而不是依靠一次长HTTP请求。取消、关闭页面、断网、超时、服务重启和实际提交后回执丢失分别定义；停止等待不伪装成撤销已保存回答。最终发布检查当前账号/原学生授权、会话快照、任务租约和问答身份。不能因另一页面更新了无关偏好而重复调用模型；确实不兼容的课程版本/权限变更必须阻止旧回答发布。

普通问答响应保留提问和回答身份、来源节点、模型、时间、补充板书及恢复位置；不返回私有答案、内部提示词、路径、任务token或其他账号记录。未完成练习的助教保持答题阶段保护，提示/帮助接触事实先保存且不能靠取消/刷新清除。旧消息与旧课堂快照仍可读取，不伪造其历史节点或轮次。

## 3. 按困惑调整讲法

提供常规提问、换例子、简化语言、补先修、比较表达五种明确意图；用户选择后看到将发送的请求，再确认发送。沿用常规模型下拉框和默认DS V4.1 Flash；一轮内固定实际模型，失败不静默改供应商。

讲法改变始终围绕当前教学目标和已许可内容：例子说明条件与结论，简化保持准确术语，先修只使用实际先修资料或明确标记为讲解建议，比较按相同维度表达。没有独立测量证据时不能宣称已找到学生的深层原因、已掌握或肯定薄弱。需要验证的理解检查属于课堂学习，不自动写掌握度。

模型返回受控文本、提炼笔记和允许的图表协议，不执行HTML或脚本。笔记按整项进入，字幕逐句播放；一轮重试不会重复添加同样的板书。回复结束后显示回到原课的具体位置，由学习者继续；不会自动跳到下一知识点、打开未曝光答案或自动安排正式测量。
